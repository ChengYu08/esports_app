模块按职责拆分为三个平级文件：
- `teen-mode.ts`：纯函数型工具层，定义 TeenModeRecord 类型及 4 位数字密码的输入过滤、完整性判断、二次确认逻辑。
- `teen-mode-store.ts`：状态与存储层，基于 `@/core/storage/storage` 维护弹窗缓存（dontAsk / lastDismissedDate）和服务端开启状态的本地镜像（按 userId 分 key），并通过 `statusListeners` Set + `subscribeTeenModeStatus`/`publishTeenModeStatus` 暴露发布-订阅式状态广播接口。
- `teen-request-guard.ts`：请求守卫层，通过 `createTeenRequestGuard()` 生成带 session/revision 双版本号的快照对象，用于在登录会话切换或状态失效时丢弃过期的异步结果，保证最终落地的状态一致性。
依赖方向单向向外：store 依赖 core storage 与 teen-mode.contract；guard 无外部依赖；teen-mode.ts 为纯工具，被 store 和上层 UI 共同消费。

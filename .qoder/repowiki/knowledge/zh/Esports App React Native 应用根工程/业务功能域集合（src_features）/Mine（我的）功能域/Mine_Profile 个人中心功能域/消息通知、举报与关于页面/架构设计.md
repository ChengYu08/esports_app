三个独立的 Expo Router 页面组件，均位于 `src/features/mine/screens/` 下，遵循统一的 UI 组合模式：通过 `ScreenHeader` 提供导航头（含返回按钮与标题）、使用 `useSafeAreaInsets` 适配刘海区域、以 `ScrollView` 承载内容。
- `MessageNotificationScreen.tsx`：基于自定义 Hook `useSmsNotifyStatus` / `useUpdateSmsNotify` 拉取并更新短信通知开关，内嵌 `NotificationSwitch` 组件，使用 `react-native-reanimated` 的 `useSharedValue` + `interpolateColor` 实现轨道色与滑块动画。
- `ReportScreen.tsx`：本地状态管理举报原因单选与描述文本，通过 `submitReport` API 提交，依赖 `@esports/auth` 的 `useAuthStore` 获取 accessToken。
- `AboutScreen.tsx`：读取 `expo-constants` 版本号，调用 `useAppUpgradeStore.checkNow()` 执行应用内升级检测，并通过 `openInAppWebView` 打开协议链接。
三者不互相依赖，仅共享 `shared/ui` 中的通用 UI 与 `features/mine/hooks` 中的数据层 Hook。

- 每个屏幕以 `export default function XxxScreen()` 命名导出，并在顶部使用 `useSafeAreaInsets()` 为 `ScreenHeader` 动态设置 paddingTop 与高度。
- 返回按钮统一通过 `router.back()` 或 `onBack={() => router.back()}` 实现，跳转到子功能则用 `router.push("/xxx")`。
- 可点击列表项使用 `Pressable` 并传入 `accessibilityRole="button"` 与 `accessibilityLabel`，同时用 `({ pressed }) => [styles.row, pressed && styles.pressed]` 表达按下态。
- 异步错误统一通过 `error instanceof Error ? error.message : "默认文案"` 取提示文本，再经 `showToast` 或局部 state 反馈给用户。
- 需要鉴权的副作用在操作前调用 `requireLogin()` 守卫，未登录时由该函数内部处理跳转，避免在组件内重复写登录检查。

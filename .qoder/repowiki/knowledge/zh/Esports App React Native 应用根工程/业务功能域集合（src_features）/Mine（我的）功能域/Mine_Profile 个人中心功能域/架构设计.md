该模块以 `screens/MineScreen.tsx` 作为 Mine Tab 根容器，由 `mine_shell_profile_relation` 子模块负责在 Mine、Profile、ProfileRelation 之间做路由跳转；其余子模块（`profile_editing`、`account_security_settings`、`notification_report_about`、`teen_mode`、`companion_dashboard`、`diamonds_recharge_payment`）各自提供一组 React Native 页面与 `components/` 下的可复用表单/弹窗组件，统一挂载到这些页面的导航栈中。跨子模块的共享能力集中在 `components/`：如 `TeenModeGate`、`RealNameVerificationSheet`、`CompanionAgreementSheet`、`StarPaymentSheet`、`WechatPayQrModal`、`ProfileActionsSheet` 等被多个页面复用的无状态或半状态组件，而业务状态则通过各子模块自身的 hooks/store 管理，模块内部不引入额外的全局总线。

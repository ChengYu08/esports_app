模块由四个并列的 React Navigation 页面组成，均位于 `src/features/mine/screens/`：
- `CompanionDashboardScreen.tsx`：仪表盘入口，聚合账户余额、接单量、服务开关、语音试听与图片预览，通过 `useLocalSearchParams` 读取 `gameId` 并调用 `useCompanionOverview` / `useManagedGame` 获取数据，使用 `companionManagementApi` 直接更新服务状态。
- `CompanionIntroScreen.tsx`：能力介绍编辑器，基于 `COMPANION_INTRO_MAX_LENGTH` 做字数限制，调用 `api.updateIntro`。
- `CompanionGalleryScreen.tsx`：技能截图画廊，结合本地选择器 `companion-gallery-picker`、校验器 `companion-gallery-selection`、上传器 `companion-upload` 与服务端 API，维护 pending images、已删除 ID、已上传 URL 等多份异步状态，按「先上传新图 → 再删除旧图 → 逆序持久化」顺序提交。
- `CompanionIncomeScreen.tsx`：竹子明细列表，基于 `@tanstack/react-query` 的 `useInfiniteQuery` + `walletPage` 分页加载。

依赖方向单向向外：页面 → `../components`（如 `CompanionDashboardHeader`、`CompanionImagePreview`、`CompanionIncomeEntry`）、`../hooks/use-companion-management`、`../api/companion-management.api`；不反向引用其他 feature。所有页面共享同一 Header 组件并通过 `expo-router` 的 `router.push` / `router.back` 导航。

- 页面通过 `useLocalSearchParams<{ gameId?: string }>()` 读取游戏上下文，并以 `!managed.enabled || !gameId` 作为不可用态统一渲染 `EmptyState`。
- 异步数据展示统一采用 `EmptyState` / `ErrorState` / `LoadingState` 三态分支，错误态提供 `onRetry` 触发 `refetch()`。
- 对外部 API 调用前统一执行 `managed.assertCurrentAccount()` 校验当前账号，失败后通过 `showToast` 提示并返回。
- 写操作在 try/catch 中先执行业务 API，再调用 `managed.invalidate()` 使查询失效，最后在 finally 中清理 busy/ref 等状态。
- 可滚动容器统一设置 `contentInsetAdjustmentBehavior="never"`、`automaticallyAdjustContentInsets={false}` 以避免 iOS 自动偏移，并根据 `useSafeAreaInsets().bottom` 动态计算底部 padding。

- 对外暴露的入口组件（TeenModeGate、TeenModeScreen）接收 token/userId 后转交给同名的 `*Session` 子组件，并通过 `key={token}:${userId}` 在换号时强制重建实例以隔离会话。
- 所有异步副作用都通过 `createTeenRequestGuard()` 生成的 guard 对象进行 `beginSession` / `snapshot` / `isSessionCurrent` 校验，确保旧的网络响应不会覆盖新的账号或操作结果。
- 服务端的锁定窗口配置（`lockStartHour`/`lockEndHour`）在 Gate 与 Screen 两处均通过 `fetchTeenModeConfig` 拉取并降级到默认 22:00-次日 6:00，失败路径保持静默不阻断主流程。
- 用户输入密码采用四步数字框配合 `filterDigits` + `isPasswordComplete` + `TEEN_MODE_PASSWORD_LENGTH` 常量校验，并在设置阶段先存 `firstPassword` 再二次比对提示不一致。

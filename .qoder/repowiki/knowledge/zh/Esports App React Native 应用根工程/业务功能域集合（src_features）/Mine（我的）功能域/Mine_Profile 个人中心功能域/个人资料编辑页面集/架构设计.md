本模块由三个并列的 React Native 页面组件构成：`EditProfileScreen.tsx` 作为聚合入口，以 `EditRow` 列表渲染昵称、签名、性别、生日四行；其中昵称和签名跳转至独立全屏编辑页（`EditNicknameScreen.tsx`、`EditSignatureScreen.tsx`），性别通过 `BottomSheet` 浮层立即保存，生日通过 `BirthDatePickerSheet` 滚轮弹层保存，头像则经 `media-picker` 路由裁剪后走 OSS 直传流程。所有写操作统一调用 `clientAuthApi.updateProfile`，成功后通过 `toAuthUser` + `saveAuthSession` + `setSession` 三件套刷新本地状态，错误则经 `showToast` 反馈。依赖方向单向指向 `@/features/auth/*`、`@/shared/ui/*` 与 `expo-router`，页面之间仅通过路由参数传递初始值，无共享状态。

三个并列的屏幕组件，均位于 `src/features/mine/screens/` 下，作为「我的」模块中账户安全相关能力的 UI 层：
- `AccountSecurityScreen.tsx` 仅做导航聚合：读取 `useAuthStore.user` 展示实名认证与手机号（含掩码），并通过 `expo-router` 跳转至 `/real-name-verification`、`/change-password`、`/blacklist`、`/account-cancellation`。
- `BlacklistScreen.tsx` 基于 `react-native-gesture-handler` 的 `Swipeable` 实现左滑删除；数据读写委托给 `@/features/mine/blacklist` 的 `readBlacklist` / `removeFromBlacklist`，通过 `requireLogin` 守卫登录态后调用 API。
- `AccountCancellationScreen.tsx` 是核心业务页面：通过 `clientAuthApi.queryCancellationStatus` 获取冷静期天数，走申请→短信验证码→确认注销三段式流程；确认后调用 `leaveVoiceRtc` / `leaveVoiceChatRoom` 清理语音房间、`messageStore.reset()` 清空消息、`clearAuthSession` + `clearSession` 清凭证，并把冷静期截止时间持久化到 `cancellation-cooling-store`。
依赖方向单向向下：UI → `@esports/auth` store / `client-auth.api` → 业务 store 与工具模块；不反向引用其他 screen。

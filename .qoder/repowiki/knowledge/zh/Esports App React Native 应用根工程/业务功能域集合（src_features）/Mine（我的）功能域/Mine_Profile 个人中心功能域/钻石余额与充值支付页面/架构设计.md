模块由三个并列的屏幕组件组成，按平台与职责拆分：
- `MyDiamondsScreen.tsx`：仅消费数据，使用 react-query 的 `useQuery` + `useInfiniteQuery` 拉取 `fetchStarBalance` 与分页充值记录，并通过 `router.push('/star-recharge')` 导航到充值页。
- `StarRechargeScreen.tsx`：iOS 专属充值页，依赖 `@/features/iap/use-star-iap` 钩子完成 App Store 内购，通过 `handleDelivered` / `handlePending` 回调刷新余额并弹出提示。
- `StarRechargeAndroidScreen.tsx`：Android 专属充值页，调用 `/features/mine/api/recharge.api` 的 `fetchRechargeConfig`、`createPayOrder`、`createAppPayOrder` 等接口，根据渠道 key 区分微信与支付宝，微信走扫码弹窗 `WechatPayQrModal`，支付宝通过原生模块 `modules/alipay-payment` 唤起收银台。

依赖方向单向向外：屏幕 → API 层 → 共享 UI/导航；iOS 与 Android 两条充值路径互不引用，仅在 MyDiamonds 中统一入口跳转。

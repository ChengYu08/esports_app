- 充值相关数据读取均通过 `fetchStarBalance(token)` 主动刷新，并在失败时保留上次已知余额而非置空。
- 路由参数 `shortfall` 统一以 `Array.isArray(route.shortfall) ? route.shortfall[0] : route.shortfall` 解构后再做 `Number.isFinite` 校验。
- 用户协议勾选状态与购买按钮禁用逻辑在两个充值页中保持一致：未勾选协议或无选中商品时禁止下单。
- 错误与提示统一通过本地 `prompt: { title, message }` 状态配合 `AppPrompt` 组件展示，而不是直接 alert。

本模块由三层组成：
- 入口层 `TeenModeGate`：作为 App 全局门控，负责从服务端拉取 `/youth/config` 锁定窗口、同步 `teen-mode-store` 中的全局状态、通过 `createTeenServerClock` 校准本地时间并判定是否进入锁定；同时根据 `shouldShowTeenPopup` 控制 `TeenModePromoDialog` 的弹出。
- 页面层 `TeenModeScreen`：承载青少年模式的完整用户流程（overview → setFirst/setConfirm → openWithPassword/openWithPasswordConfirm → disable），内部以 `Phase` 状态机驱动表单；登录态变化时通过 `key={token:userId}` 重建子组件 `TeenModeScreenSession` 隔离会话。
- 弹窗层 `TeenModePromoDialog`：纯展示型 Modal，仅负责 UI 交互并把「后续不再重复弹出」标记回传给父组件。

依赖方向单向向下：Gate → Screen → TeenModePromoDialog；所有网络请求经 `@/features/mine/api/teen-mode.api`，状态持久化经 `@/features/mine/teen-mode-store`，并发安全统一委托给 `@/features/mine/teen-request-guard` 提供的 `createTeenRequestGuard()` + `snapshot`/`isSessionCurrent` 机制，避免旧响应覆盖新账号或新操作。锁定时段文案来自 `utils/teen-lock-window`，促销策略来自 `utils/teen-popup`。

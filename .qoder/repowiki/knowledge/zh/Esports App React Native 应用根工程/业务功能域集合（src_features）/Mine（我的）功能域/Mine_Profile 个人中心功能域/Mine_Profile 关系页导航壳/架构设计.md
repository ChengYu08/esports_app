本模块由三个 Expo Router 页面组成，按路由层级组织：
- `MineScreen.tsx`：Mine 首页，通过 `router.push('/profile-relations', { userId, type, clubId })` 跳转到关系页；同时维护登录态、关注数、星余额等状态，并在 `useFocusEffect` 中刷新当前用户资料。
- `ProfileScreen.tsx`：个人主页详情，读取 `clubId` / `userId` / `fromSearch` 等路由参数，组合 `useProfileDetail`、`useUserFollowState`、`useToggleUserFollow` 等 hook，承载技能、评价、黑名单、下单等完整业务。
- `ProfileRelationScreen.tsx`：关注/粉丝分页列表，复用 `useUserFollowPage` + `useToggleUserFollow`，提供「回关」和「聊一聊」操作并反向跳转 `/profile` 或 `/chat/[id]`。
依赖方向单向向下：Mine → ProfileRelation → Profile/Chat，所有跨页面跳转均经 `expo-router`，数据访问统一下沉到 `@/features/mine/hooks/*` 与 `@/features/mine/api/*`，UI 组件来自 `@/shared/ui/*`，不直接耦合业务 API。

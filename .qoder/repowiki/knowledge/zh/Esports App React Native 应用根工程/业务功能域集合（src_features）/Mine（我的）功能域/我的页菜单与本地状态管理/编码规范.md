- 本地可序列化状态以 `xxx_STORAGE_KEY = "esports.mine.*"` 常量命名，并通过 `storage.get` / `storage.set` 读写。
- 从存储读取的值统一经 `JSON.parse` 后用类型守卫（如 `isBlacklistEntry`）过滤后再返回，异常路径回退为空值或默认对象。
- 需要跨组件共享的状态在模块顶层维护单例缓存变量（如 `cachedSettings`、`blacklistListeners`），并提供显式的初始化入口（如 `ensureNotificationSettingsLoaded`）。
- 可变状态变更后先写后端（黑名单场景）或直接写 storage，再触发通知回调或返回最新缓存，保证本地镜像与远端最终一致。

模块由三个独立子文件组成，各自维护一类本地可序列化状态，并通过 `@/core/storage/storage` 持久化到 AsyncStorage：
- `mine-menu.ts`：纯函数式入口解析器，优先消费服务端下发的 `sidebarMenus`（仅保留 `KNOWN_MENU_KEYS` 白名单），未下发时按 `hasClub` / `isCompanion` 身份字段推导兜底菜单，无副作用。
- `blacklist.ts`：黑名单条目列表的本地缓存 + 后端同步。通过 `addBlacklistedUser` / `removeBlacklistedUser` 调用远端 API，成功后再更新本地 JSON 并广播变更；使用 `Set<BlacklistListener>` 实现发布订阅，供列表页等订阅刷新。
- `notification-settings.ts`：免打扰开关的单例缓存，通过 `ensureNotificationSettingsLoaded` 懒加载一次后复用 `cachedSettings`，并提供 `isQuietHours` / `isMessageNotificationMuted` 时间窗口判断逻辑。
依赖方向单向指向 `@/core/storage/storage` 和 `@/features/mine/api/blacklist.api`，本模块不引入任何 UI 组件或路由。

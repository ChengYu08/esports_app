模块按职责拆分为三个独立工具文件，无内部依赖关系：
- `companion-document-picker.ts`：基于 `expo-document-picker` 的 `getDocumentAsync`，封装伴生体音频选取，限定 MIME 类型为 `audio/*` 和 `application/ogg`。
- `companion-gallery-selection.ts`：纯函数式图片筛选器，通过白名单 MIME 集合与正则后缀双策略判断是否支持 JPG/PNG/WebP，并拒绝超过 2MB 的文件，返回 `{ accepted, warnings }` 供上层展示提示。
- `companion-upload.ts`：上传层，调用 `@/features/auth/client-auth.api.getOssSts` 获取 STS 凭证后复用 `@/features/auth/oss-upload.uploadClientObject` 完成直传；区分 `image` 与 `voice` 两种 kind，分别映射到 OSS 路径标识 `107` / `111`，并在本地校验文件大小、推断默认扩展名（语音 m4a、图片 jpg）。
依赖方向单向向外：本模块仅消费 auth 模块的鉴权与 OSS 上传 API，不被其它 feature 反向引用。

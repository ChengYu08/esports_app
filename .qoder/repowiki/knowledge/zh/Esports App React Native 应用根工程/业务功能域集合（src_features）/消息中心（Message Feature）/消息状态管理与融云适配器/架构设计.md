模块由三层构成：
- 数据层 `message-state.ts`：定义不可变的数据结构（`ManagedMessage`、`MessageConversation`、`MessageHistoryPage`）及纯函数式合并/排序工具（`mergeConversations`、`mergeMessages`、`prependHistory`、`replacePendingMessage`、`markMessageFailed`），不包含副作用。
- 适配层 `MessageAdapter`（在 `message-store.ts` 中导出接口）：将融云 SDK (`rongcloud-im`) 暴露为统一 API，使 store 不直接依赖融云；`createAdapter()` 把 `initializeRongCloud`、`subscribeRongMessageEvents` 等具体实现桥接成 store 方法。
- 状态层 `message-store.ts`：使用 `zustand/vanilla` 的 `createStore` 创建全局 store，维护连接状态、会话列表、按 peerId 分组的消息、历史记录游标、黑名单、在线状态等；通过订阅融云的长连接事件回调驱动状态更新，并内置断线自动重连（`MAX_RECONNECT_ATTEMPTS=10`）、离线补偿消息识别、空列表延迟重试等生命周期逻辑。
- 搜索层 `message-search.ts`：提供无副作用的 `filterMessageConversations`，复用 `system-conversations` 做系统会话与黑名单过滤。
依赖方向单向：store → message-state / rongcloud-im / system-conversations / blacklist / notification-settings / client-auth-api；search 仅依赖 state 与 system-conversations。

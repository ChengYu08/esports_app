- 对持久数据的变更一律以纯函数形式放在 `message-state.ts` 中（如 mergeConversations、mergeMessages、prependHistory），store 只负责调用这些函数产生新状态。
- 对外部 IM 能力通过 `MessageAdapter` 接口抽象，store 内部用 `createAdapter()` 注入融云实现，便于替换或测试。
- 长连接订阅的生命周期（connection/conversation/read/messages/blacklist）在 store 顶层变量中以 stop 函数保存，并在 reset/disconnect 时清理。
- 本地发送的消息以 pending 状态预插入，使用 `clientId`（格式 `local-${now()}-${seq}`）作为临时 key，收到服务端回执后通过 `replacePendingMessage` 按 clientId 替换。

本模块以 `message-store.ts`（基于 Zustand 的会话与历史消息状态）为中央状态源，由 `rongcloud-im.ts` / `rong-history.ts` 作为融云 SDK 适配器注入；上层通过 `chat-message.ts` 对消息进行类型化封装。
- 事件入口：`rong-command-dispatch/RongCommandHost.tsx` 在根组件挂载时订阅融云命令，经 `rong-command-registry` 分派到具体 handler；`action-command/register-action-command-handlers.ts` 注册 QUICK_MATCH_NOTICE、ORDER_NOTIFY 等操作型命令，将信令转为全局 ActionNotice 并通过 `notification-hub.ts` 的 `dispatchInAppNotification` 触发顶部浮层。
- UI 层：`screens/MessageScreen.tsx` 与 `ChatScreen.tsx` 消费 Zustand store 渲染列表与详情，`components/MarkdownMessage.tsx`、`CsInviteCard.tsx`、`OrderNotifyCard.tsx` 按消息 kind 渲染卡片。
- 跨子模块契约：所有子模块围绕 `ChatMessage` 类型（`message.types.ts` + `chat-message.ts`）与 Zustand store 通信，避免直接依赖融云 SDK；`system-conversations.ts` 与 `conversation-loader.ts` 提供系统会话初始化，供各子模块复用。

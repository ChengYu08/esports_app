模块围绕 `@rongcloud/react-native-im-wrapper` 原生 SDK 做一层适配，分为三个层次：
- 运行时桥接层 (`rongcloud-im.ts`)：通过 `require` 动态加载 SDK、环境配置与认证 API，实现连接状态管理、会话/消息映射 (`mapRongMessage`)、图片下载、订阅广播（conversation/message/command/chatRoom* 等 listener Set）及可用性检测 `isRongCloudAvailable`；对外暴露 `subscribeRongCommands`、`toManagedMessage` 等接口。
- 历史消息层 (`rong-history.ts`)：以 `RongHistoryEngine` (Pick<RCIMIWEngine>) 抽象引擎能力，按策略顺序调用 `getMessages`，优先 REMOTE 再回退 LOCAL_REMOTE，避免本地库为空导致聊天页空白。
- 命令分发层 (`rong-command-dispatch/`)：`types.ts` 定义 `RongCommandHandler` 契约；`rong-command-registry.ts` 用全局 Map 维护已注册 handler，支持带鉴权过滤的 `dispatchRongCommand`；`RongCommandHost.tsx` 作为 React 根组件在挂载时统一注册 action/reception/voice-room 三类命令处理器并订阅融云命令流。
依赖方向单向：command-dispatch → rongcloud-im → rong-history → SDK；模块内部不反向依赖业务页面。

- 对原生 SDK、环境配置和认证 API 均使用 try/catch + require 的动态加载方式，在 web 或非目标环境下降级返回空值而非抛错。
- 事件监听器以模块级 Set 集中维护（conversationListeners、messageListeners、chatRoomMessageListeners 等），并通过导出 subscribe 函数供外部订阅。
- 命令处理采用「注册表 + 分发」模式：handler 通过 `registerRongCommandHandler` 注册到全局 Map，`dispatchRongCommand` 统一遍历并按 `requireAuth` 进行鉴权过滤。
- 历史消息拉取遵循「远程优先、本地兜底」策略，先提交 REMOTE 策略回调，失败或无结果时再回退 LOCAL_REMOTE，并以 settled 标志防止重复 resolve。

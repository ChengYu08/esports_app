- 命令处理器以 `handleXxx(command)` 函数形式导出，先做命令名与 `senderId === PLATFORM_NOTICE_USER_ID` 双重守卫再进入业务逻辑。
- 通知去重使用模块级 `Set<string>` 缓存 key，并在 `onDisappear` 回调中释放，避免重复弹条。
- 离线积压消息通过比较 `command.sentTime` 与当前时间是否超过 `COMMAND_STALE_MAX_MS` 阈值来丢弃，并以 `logger.warn` 记录 skew。
- ActionNotice 统一通过 `actionNotice.push(id, payload, callbacks)` 创建，id 采用前缀加业务标识（如 `qm:${requestNo}`、`pay:${orderNo}`）。

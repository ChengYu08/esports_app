模块按 `screens/`（页面）与 `components/`（可复用行/卡片）两层划分：
- `screens/MessageScreen.tsx` 为会话列表入口，负责拉取会话、处理连接状态与未读数、通过 `router.push('/chat/[id]')` 导航到聊天页。
- `screens/ChatScreen.tsx` 是核心聊天页面，使用 `FlatList` 渲染时间分隔符与消息行，组合 `MarkdownMessage`、`OrderNotifyCard`、`CsInviteCard` 等组件显示不同消息类型，并通过 `useMessageStore` 调用 `sendText/sendImage/retryMessage/loadOlder` 等动作完成收发与历史加载。
- `components/` 下所有子组件仅消费 `../message-store`、`../message-avatar`、`../system-conversations` 等共享逻辑，不直接访问路由或网络层；`MessageHeader`、`MessageListItem` 作为纯展示组件由两个 screen 复用。
- 依赖方向单向：screens → components → shared store / helpers；UI 状态统一来自 `message-store` 与 `@esports/auth`，避免在组件内维护连接态。

- 页面通过 `useMessageStore(state => state.xxx)` 解构式订阅单一字段，而非整对象订阅，以减少重渲染。
- 会话 ID 在进入页面前统一经 `normalizeSystemConversationId` 归一化，再交由 `isSystemConversationId` / `isSelfConversationId` 做分支判断。
- 列表项组件使用 `memo` 包裹并以稳定引用函数（`useCallback`）传递 `onPress` / `renderItem`，配合 `keyExtractor` 保证 FlatList 命中 memo 优化。
- 样式采用 `StyleSheet.create` 就近定义，颜色与尺寸以硬编码字面量形式写在样式表中，不使用外部主题变量。

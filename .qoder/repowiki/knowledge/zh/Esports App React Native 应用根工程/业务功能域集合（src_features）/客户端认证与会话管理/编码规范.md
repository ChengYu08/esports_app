- 对持久化的读写通过 `session-contract.ts` 的 `SessionStorage` 接口进行，避免直接依赖具体存储实现，便于测试替换。
- 对外暴露的 API 采用 `createXxx` 工厂函数（如 `createClientAuthApi`、`createClientAuthContract`），同时导出默认单例实例供常规使用。
- 登录流程的错误路径优先抛出带中文语义的 `Error`（如「统一登录未返回 idToken」「业务 token 为空」），由调用方捕获并展示。
- 需要兼容多端时，通过 `Platform.OS` 与 `expo-constants` 动态区分 iOS / Android / H5，并在签名头中携带对应平台信息。

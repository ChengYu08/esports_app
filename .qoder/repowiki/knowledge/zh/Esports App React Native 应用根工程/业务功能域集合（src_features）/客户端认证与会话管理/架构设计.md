模块以 `client-auth-flow.ts` 为登录编排入口，串联 `client-auth.api.ts`（通过 `crypto-js` 生成 H5 签名头并调用 `apiClient`）与 `session-persistence.ts`（将 `PersistedAuthSession` 写入 `secureStorage`），并在登录后异步查询陪玩身份。
- 存储抽象：`session-contract.ts` 定义 `SessionStorage` 接口与 `readPersistedAuthSession/savePersistedAuthSession/clearPersistedAuthSession`，`session-persistence.ts` 仅做适配层，使单元测试可注入 mock storage。
- API 分层：`client-auth.contract.ts` 暴露 `createClientAuthContract` 契约，`client-auth.api.ts` 提供带签名的 `requester` 实现，并通过 `createClientAuthApi` 导出单例 `clientAuthApi`。
- 辅助领域：`cancellation-cooling.ts` 提供冷静期时间戳解析/格式化/活跃性判断；`password-login-error.ts`、`auth-phone.ts` 处理密码错误码映射与手机号回退；`sign-out.ts` 按“先释放语音/IM → 清本地凭证 → 失效服务端 token”的顺序执行登出。
- 依赖方向单向向外：本模块依赖 `@esports/auth`、`@esports/sso-sdk`、`@/core/*`、`@/features/message`、`@/features/voice-room`，不被其他 feature 反向引用。

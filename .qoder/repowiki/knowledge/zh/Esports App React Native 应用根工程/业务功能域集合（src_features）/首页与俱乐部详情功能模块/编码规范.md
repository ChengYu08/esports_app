- API 调用统一通过 `apiClient` 发起，并以 `requireSuccess` 校验返回码，失败时抛出带中文消息的 Error。
- React Query hook 使用以语义前缀开头的 queryKey（如 `home-clubs`、`club-detail`、`club-companions`），并在 enabled 中结合 HomeTab 与 focused 状态控制加载时机。
- 可组合的业务算法（轮播缓冲、滚动状态机、横幅跳转协议）抽离到根级纯函数文件，并通过单元测试（`.test.ts`）覆盖边界情况。
- 对外暴露的类型集中在 `api/home.types.ts`，API 函数内部使用私有 Api* 中间类型完成字段映射后再返回稳定结构。

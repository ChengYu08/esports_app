模块按 React Native feature 目录惯例分层组织：
- `screens/`：顶层路由入口（HomeScreen、ClubDetailScreen、PriceListScreen），HomeScreen 通过顶部频道 tab（home/god/ranking/court）组合其他 feature 的子屏幕。
- `components/`：纯展示组件（ClubCard、HomeHeader、HomeBannerCarousel、HomeSkeleton 等），仅消费 hooks 返回值进行渲染。
- `hooks/`：基于 @tanstack/react-query 的数据层，`use-home-data.ts` 导出 useHomeBanners/useHomeGames/useHomeClubs/useClubDetail 等 hook，统一 queryKey 命名并控制 enabled/staleTime；`use-club-online-counts.ts` 单独维护可见卡片在线人数查询。
- `api/`：HTTP 调用与类型定义，`home.api.ts` 通过 `@/core/network/api-client` 请求后端并以 `requireSuccess` 校验响应，对外暴露 fetchXxx 函数；`home.types.ts` 集中业务类型。
- 根级工具文件：`banner-loop.ts` 提供无限轮播缓冲页算法；`club-list-scroll.ts` 用不可变状态机（begin/markEndReached/settle）驱动列表滚动时暂停轮播与挂起分页；`home-banner.contract.ts` 定义横幅资源位代码与按端跳转协议解析（ROUTE/URL/none）。依赖方向为 screens → hooks → api，UI 与业务逻辑解耦。

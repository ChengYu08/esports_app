- 跨平台差异通过 `Platform.OS === 'android'` / `'ios'` 分支与同名 `.ios.tsx` 文件（如 `PushyUpdateHost.ios.tsx`）实现，非目标平台直接透传 children。
- 升级类门控逻辑被拆分为纯函数（`decideAppUpgrade`、`decideOtaGate`、`decideMd5Verification`），便于单元测试覆盖判定规则。
- 异步副作用统一通过 React 宿主组件（`AppUpgradeHost`、`PushyUpdateHost`）在隐私同意后挂载时触发，避免在渲染阶段执行网络或原生调用。
- 可复用的冷启动检查通过共享 Promise (`startupCheckPromise`) 与 `kickOffStartupCheck` / `whenStartupCheckSettled` 暴露给其他 feature 等待结果，避免重复请求。

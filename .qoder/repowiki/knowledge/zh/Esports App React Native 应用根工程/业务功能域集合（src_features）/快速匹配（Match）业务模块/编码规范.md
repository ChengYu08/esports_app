- API 层对服务端返回的 `ApiEnvelope<T>` 统一通过 `requireSuccess` / `requireVoidSuccess` 校验，失败时抛出带友好 message 的 Error。
- 前后端字段类型差异在 `match.api.ts` 内通过 `toNumber`、`toOptionalString`、`toTrimmedOptional`、`mapCardItems` 等转换函数集中清洗后再赋给领域类型。
- 易变的外部副作用（toast、confirm、router.replace、exitVoiceRoom）通过参数或独立函数注入，使流程函数可被测试覆盖。
- 跨请求幂等保护通过模块级 Set（如 `pendingRequestNos`）配合导出 reset 函数实现，避免重复提交。
- 错误路径优先抛出自定义 Error（如 `StarNotEnoughError`），上层根据 error instanceof 判断走分支而非解析字符串。

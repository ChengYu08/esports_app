- 后端异构字段通过 `stringValue` / `numberValue` 多键回退读取，未命中时返回 `undefined`，避免空引用。
- 后端状态码到前端展示状态的转换集中在 `ORDER_STATUS_BY_RAW` 映射表，未知值兜底为 `pendingPayment`。
- 订单动作 (`actions`) 按 `status` + `isFreeOrder` + `settled` + `serviceEnded` 等条件在 `mapOrder` 中集中生成，而非分散在 UI 层。
- 分页查询统一由 `useOrderPage` 基于 `useInfiniteQuery` 实现，queryKey 固定形如 `["orders", scope, filter, userId]`，便于 `invalidateOrderQueries` 精准失效。
- 对外暴露的领域逻辑（时间格式、金额计算、倒计时、多陪校验等）以独立纯函数文件组织，并通过同名 `.test.ts` / `.test.mjs` 单元测试覆盖。
- TypeScript 类型在 `order.types.ts` 集中声明，其他文件仅 import type，保持运行时零侵入。

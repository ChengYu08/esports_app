- API 契约通过 `createRankingContract(requester)` 工厂函数返回对象，再由 `ranking.api.ts` 用 `apiClient` 注入，便于在测试中替换请求实现。
- 所有接口响应先经 `requireSuccess` 校验 `code === 'SUCCESS'`，失败时抛出带用户可读消息的 Error，再对字段做类型归一化（如 `String(userId)`、`Number(metricValue)`）。
- 榜单枚举（boardCode、rankType）以 `as const` 数组定义在 `ranking.config.ts` 中，并通过 `getRankingBoard` 等辅助函数查找，避免字符串字面量散落。
- 列表项点击跳转使用 `getRankingProfileParams` 从 `RankingItem` 派生 profile 参数，若缺少必要 ID 则返回 null 并降级为不可点击。
- 数值格式化统一走 `formatRankingMetric`，仅在 GOD 板显示距离差值，ORDER_RECEIVE/TURNOVER 分别加单位或千分位缩写。

- API 层统一使用 `ApiEnvelope<T>` 包裹响应体，并在返回前校验 `response.code === 'SUCCESS'`，否则抛出带中文提示的错误。
- Hook 层通过 `useQuery` 并以 `[category, keyword]` 作为唯一 queryKey，同时用 `enabled: keyword.trim().length > 0` 实现空关键词不触发请求。
- 搜索历史在 `search-history.ts` 中保持纯函数式操作（`addSearchHistoryEntry`、`parseSearchHistory`、`mergeLegacySearchHistory`），storage 层仅负责序列化与持久化。
- 历史条目采用统一 `SearchHistoryEntry` 结构，并通过 `entityId` 区分精确匹配（如具体俱乐部/用户）与模糊关键词，避免错误复用头像。
- UI 样式集中在 `search-typography.ts`，通过 `Platform.select` 区分 iOS PingFang SC 与 Android sans-serif 字体，并以 `StyleSheet.create` 暴露字号变体。

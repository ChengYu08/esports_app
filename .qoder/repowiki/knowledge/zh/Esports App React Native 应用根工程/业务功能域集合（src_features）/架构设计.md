本目录按业务领域横向切分子模块（activity、auth、court、home、match、message、mine、order、ranking、search、voice-room、app-upgrade/ota/iap、privacy、god），每个子模块遵循 api/components/hooks/screens 的分层结构并自包含测试；跨模块协作通过以下方式完成：
- 路由挂载集中在 `navigation/screens/`（TabPlaceholderScreen、WebViewScreen），其他子模块仅导出自身 Screen 组件供上层注册。
- 外部基础设施依赖由各自子模块封装（如 message 封装融云 IM、voice_room 封装声网 RTC + 融云、iap 对接苹果内购），对外以 hooks 或 store 形式提供能力，避免子模块直接耦合底层 SDK。
- 共享状态与契约在各子模块内部通过 `.contract.ts` / `.types.ts` 声明，由对应 `.api.ts` 消费，保证同模块内类型一致。
- 升级与热更新（app-upgrade、ota、iap）在启动阶段通过 gate 机制拦截应用流程，独立于业务模块运行。

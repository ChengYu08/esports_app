- 服务端返回字段一律经清洗后再暴露：字符串 `.trim()` 并回退空串，数字经 `toNumber` + `Math.max(0, Math.trunc(...))`，枚举值经白名单校验后兜底默认值。
- 涉及时间的逻辑将本地 `Date.now()` 与服务端 `serverTime` 分离，通过 `offsetMs = serverTime - nowMs` 校准，所有时间比较统一使用 `nowMs + offsetMs`。
- UI 组件依赖的复杂业务判定被抽取为纯函数（如 `computeActivityStatus`、`formatCountdown`），并以独立的 `.test.ts` 文件覆盖。
- 跨页面传递大段 HTML 规则时采用模块级变量 `setPendingActivityRules` / `getPendingActivityRules` 在 push 前后读写，避免放入路由 params。

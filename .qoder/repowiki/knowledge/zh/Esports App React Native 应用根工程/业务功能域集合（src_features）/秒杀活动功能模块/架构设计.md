模块按职责分为四层：
- `api/`：网络层，`activity.api.ts` 通过 `apiClient` 调用 `/client/v1/activity/detail` 与 `/client/v1/activity/publish`，使用内部 `ApiEnvelope` 泛型包络成功响应，并提供 `requireSuccess`、`toNumber`、`readButtonStatus` 等数据清洗工具，对外暴露 `fetchActivityDetail`、`publishActivity`。
- `hooks/`：React 集成层，`use-activity-detail.ts` 基于 `@tanstack/react-query` 提供 `useActivityDetail`（带稳定 queryKey）与 `useActivityCountdown`；纯倒计时逻辑下沉到 `countdown.ts` 的 `initCountdownState` / `tickCountdown` / `getServerNowMs`，便于无 React 环境测试。
- `screens/`：页面层，`ActivityLandingScreen.tsx` 组合详情查询、倒计时、状态计算与参与动作，`ActivityRulesScreen.tsx` 渲染 HTML 规则。
- 顶层 `activity-status.ts` 定义状态机 `computeActivityStatus`（优先级 DISABLED > NOT_STARTED > SOLD_OUT > ACTIVE），`activity-rules-transfer.ts` 用模块级变量在落地页 push 前写入、规则页读取 HTML 规则以绕过路由参数长度限制。
依赖方向：screens → hooks → api；状态机与规则透传为无副作用纯函数/模块变量，不反向依赖 UI。

- 组件文件命名采用 `VoiceRoomXxx.tsx` 前缀，保持语聊房域内命名空间一致。
- 本地 SVG 图标通过 `require('../../../../assets/svgs/*.svg')` 静态引入并赋值给常量后传入 `Image` 组件。
- 需要弹出层的交互（成员资料、对话、退出确认）统一封装为基于 `BottomSheet` 的 sheet 组件，并通过 `visible` + `onClose` 受控展示。
- 对外暴露的回调事件（如 `onToggleMute`、`onSend`、`onInvite`、`onMemberKicked`）在组件 props 中显式声明，由父 screen 注入具体实现，组件自身不直接调用领域 API。
- 头像资源通过 `avatarSource` 辅助函数统一处理 `//` 协议补全 `https:`，回退到本地 `defaultAvatar`。

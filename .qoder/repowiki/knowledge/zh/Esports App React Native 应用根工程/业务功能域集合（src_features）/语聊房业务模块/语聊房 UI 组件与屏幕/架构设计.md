- 目录按职责分为 `screens/`（页面容器）和 `components/`（可复用 UI 子组件），由 `VoiceRoomScreen.tsx` 作为唯一入口聚合所有子视图。
- `VoiceRoomScreen.tsx` 承担编排职责：通过 hooks（`useVoiceRoomRtc`、`useVoiceRoomMessages`、`useVoiceRoomReception`、`useVoiceRoomSessionStore`）订阅 RTC 与会话状态，再向子组件透传 props；同时处理路由参数、权限申请、退出逻辑与快速匹配联动。
- 子组件以单向数据流暴露回调接口：`VoiceRoomToolbar` 渲染输入框与操作按钮，内部组合 `VoiceRoomMicrophone` 控制麦克风；`VoiceRoomMemberSheet`、`VoiceRoomConversationsSheet`、`VoiceRoomExitDialog` 基于共享的 `BottomSheet` 弹出层展示；`VoiceRoomSpeakingWaves`、`VoiceRoomBackground`、`VoiceRoomMiniPlayer`、`VoiceRoomKickListener` 提供视觉与监听能力。
- 依赖方向为 screen → components → shared/ui + voice-room 领域模块（`voice-room.types`、`voice-room.api`、`exit-voice-room`、`member-normalize`），不反向引用；UI 样式统一使用 `StyleSheet.create`，图标通过 `require('assets/svgs/*.svg')` 静态引入。

模块按职责拆分为三文件：`voice-room.types.ts` 集中声明 `VoiceRoomMember` / `VoiceRoomMessage` / `VoiceRoomDetail` / `VoiceRoomJoinPrepare` / `VoiceRoomRtcToken` 等 DTO；`voice-room.api.ts` 通过内部 `Envelope<T>` + `unwrap` 统一处理后端返回包络（成功时取 `data ?? null`，失败抛错），对外暴露 `voiceRoomApi` 命名空间对象，封装 `/client/v1/voiceRoom/*` 下的 joined/create/detail/prepare/join/rtc/token/leave/destroy/kickOut/inviteClubService/claimClubService 等 REST 端点，并提供 `resolveVoiceRoomId` 从多层嵌套对象中递归解析房间 ID；`message-display.tsx` 是纯展示层，导出 `MessageRoleTag`、`displayMessage` 和 `messageKeyExtractor`，依赖 types 中的角色与消息类型，使用 `expo-image`、`expo-router` 和 RN StyleSheet 渲染 notice/system/chat 三类消息气泡及图片预览。依赖方向单向：api 与 UI 都只引用 types，彼此不互相导入。

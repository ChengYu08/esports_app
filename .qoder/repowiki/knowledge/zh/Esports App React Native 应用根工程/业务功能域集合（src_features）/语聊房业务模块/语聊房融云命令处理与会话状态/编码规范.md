- 命令处理器统一通过 `registerRongCommandHandler` 注册，并以 `{ id, handle }` 对象形式传入，返回取消函数供调用方保存。
- 对可能离线积压或重复投递的命令使用内存级去重集合（Map/Set）按业务键（如 `roomId_roomVersion`、`requestNo`）过滤，并在条目消失或到期后释放键值。
- 对过期/陈旧命令优先做静默丢弃并记录 `logger.warn`，附带 `stale`/`expired`/`skewMs` 等诊断字段以便区分断连重放与真实过期。
- UI 副作用（通知条、Toast、确认弹窗）与纯状态更新分离，先写 store 再触发展示层动作，失败路径回滚状态并提示用户。

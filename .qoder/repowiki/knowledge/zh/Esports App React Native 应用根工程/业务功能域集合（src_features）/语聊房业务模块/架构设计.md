本模块以 `voice-room-session.ts` 中的 `VoiceRoomSession` 作为跨子模块的共享状态中枢，所有子模块围绕它进行协作：
- 集成层（`voice-room-rongcloud.ts`、`voice-room-rtc.ts` 及其 Hook）负责对接融云聊天室与声网音视频通道，并将房间成员、麦克风、说话者等状态写入 session。
- 会话状态由 `use-sync-joined-voice-room.ts` 同步到全局活跃房间列表，供 `reception-command-handlers.ts` 注册的自定义命令（邀请进房、快速匹配创建、踢出）消费与更新。
- UI 层（`components/`、`screens/`）通过 `use-customer-service-room-flow.ts`、`use-voice-room-messages.ts`、`use-voice-room-reception.ts`、`use-voice-room-rtc.ts` 等 Hook 订阅 session，渲染工具栏、成员面板、对话抽屉、麦克风按钮等。
- 生命周期与导航（`enter-room-from-invite.ts`、`exit-voice-room.ts`、`navigate-voice-room.ts`）在路由入口处触发创建或跳转，并保证同一时刻仅存在一个语聊房页面实例。
- HTTP 接口封装与类型定义集中在 `voice-room.api.ts` 与 `voice-room.types.ts`，被集成层与 UI 层共同引用；消息展示复用 `message-display.tsx`。
- 踢出流程通过 `register-voice-room-kick-command-handlers.ts` + `voice-room-kicked.ts` 实现命令到 UI 提示再到退出导航的闭环。

本模块由三个互补的编排入口组成，围绕 `voice-room-session` 与 `voice-room.api` 协作：
- `enter-room-from-invite.ts`：对外暴露 `enterRoomFromInvite(roomId, roomVersion)`，负责校验登录态/房间状态、判断是否同房间直进、通过 `useAppConfirm` 弹窗确认切房、调用 `exitVoiceRoom` 退出当前房后再 `navigateToVoiceRoom`，并用 `pendingInviteKeys` Set 对同一 roomId+version 做防重入。
- `exit-voice-room.ts`：区分 owner（`destroy`）与普通成员（`leave`），owner 先 `markVoiceRoomIntentionalExit` 再发 HTTP；随后 `Promise.allSettled` 并行清理 RTC 与融云会话，最后 `clearActiveRoom` 重置 session store。
- `navigate-voice-room.ts`：基于 `expo-router` 实现单实例路由策略——当 `screenFocused === true` 时 `dismissTo` 原地替换 params，否则一律 `push`，避免 POP_TO 误删中间页。
依赖方向单向向外：本模块不直接操作 RTC/RongCloud SDK，而是通过 `voice-room-rtc`、`voice-room-rongcloud`、`voice-room-session` 等子模块抽象边界。

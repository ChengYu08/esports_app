- 对外部 SDK (`@rongcloud/react-native-im-wrapper`、`react-native-agora`) 统一通过带 try/catch 的 `loadSdk()` / `loadAgora()` 函数动态 `require`，失败时返回 null 而非抛错，使 web 或无配置环境可安全调用。
- 跨文件共享的引擎单例（engine、handler、activeChannelName、joinedChatroomIds）采用模块级变量 + 初始化守卫（如 `listenersInstalled`、`enqueueRtcOp` Promise 链）避免重复创建。
- 加入房间类 API 在成功时记录已加入 ID（`joinedChatroomIds.add`），离开时先删除本地标记再调用 SDK leave，以容忍服务端踢出后本地仍认为在线的状态漂移。
- 错误信息统一使用中文模板字符串包裹错误码，如 `加入语聊房失败（${code}）`、`声网进房失败（${result}）`，便于日志定位。
- 高频回调（Agora `onAudioVolumeIndication`）在 Hook 层做去抖与差量比较后再更新 state，避免 200ms 级别回调触发整屏重渲染。

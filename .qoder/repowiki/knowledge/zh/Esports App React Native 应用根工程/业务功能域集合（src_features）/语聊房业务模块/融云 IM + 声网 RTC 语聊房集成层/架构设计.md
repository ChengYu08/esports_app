模块由三个文件组成清晰的三层：
- `voice-room-rongcloud.ts`：封装融云 IM 聊天室能力（join/leave/history/send、成员与消息订阅），通过 `@rongcloud/react-native-im-wrapper` 动态 require 加载 SDK，维护 `joinedChatroomIds` 单实例去重，并将原始 `RCIMIWMessage` 归一化为内部 `RoomMessage` 结构。
- `voice-room-rtc.ts`：封装声网 RTC 引擎，通过 `react-native-agora` 动态加载；使用 `enqueueRtcOp` 串行化所有 join/leave 操作以避免 -17 并发冲突，维护全局 engine/handler/channelName/callbacks 单例，并暴露 `VoiceRtcCallbacks` 事件接口。
- `use-voice-room-rtc.ts`：React Hook 编排层，串联 `voiceRoomApi`、`joinVoiceChatRoom`、`joinVoiceRtc`，负责邀请校验、历史消息合并、远端用户 profile 异步拉取、说话人音量迟滞判断（500ms hysteresis）以及将 IM 和 RTC 的回调映射到 `useVoiceRoomSessionStore` 的成员状态。
依赖方向单向：Hook → (rongcloud + rtc) → 外部 SDK，Hook 不直接依赖任何原生包，SDK 通过 try/catch + dynamic require 降级返回 null，保证 web 或无配置环境可用。

- 每个 withXxx.js 插件通过 createRunOncePlugin(withXxx, TAG, '1.0.0') 注册，并使用固定 TAG 字符串作为生成标记实现幂等（已包含则跳过注入）。
- 对 Gradle 文件的增改使用 withProjectBuildGradle / withAppBuildGradle + 正则精确锚点替换（如 allprojects {\n repositories {），而非直接拼接末尾，以兼容 Gradle 9 移除裸 maven() 的变化。
- 需要跨渠道凭证的插件集中维护 VENDOR_PROPS 数组，从 process.env.MI_PUSH_APPID 等环境变量读取并按 key 去重写入 gradle.properties。
- 直接操作文件系统（drawable、图片拷贝）统一放在 withDangerousMod 中执行，并在目标目录先 mkdirSync({ recursive: true })。
- 对宿主模板结构（styles.xml 中的 Theme.App.SplashScreen、MainActivity.kt 中 expo-splash-screen 生成的 block）进行存在性校验，缺失时抛出含 TAG 的错误信息以便快速定位。

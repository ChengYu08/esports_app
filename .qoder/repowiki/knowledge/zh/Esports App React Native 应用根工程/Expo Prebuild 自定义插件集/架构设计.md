模块由一组相互独立的 withXxx.js 插件构成，每个文件导出一个通过 createRunOncePlugin 注册的 Expo Mod Plugin（少数如 withAndroidFullscreenSplash 直接导出函数供外部编排）。依赖方向单向：插件 → @expo/config-plugins API（withAppBuildGradle / withAndroidManifest / withDangerousMod 等）→ 原生工程文件。按职责拆分为三类：
- 第三方 SDK 接入：withRongCloudPush 系列（android 侧注入 vendor maven 仓库、gradle.properties 凭证、app/build.gradle 依赖；iOS 侧 withRongCloudIosPush 单独处理）。
- Android 原生资源注入：withAndroidFullscreenSplash 修改 styles.xml 与 MainActivity.kt 并写 drawable 资源；withVoiceRoomBackground、withPzOneClickLibs、withRongCloudAndroidInit/PushClick 同理。
- 构建/平台修补：withNodeCommandUtf8 通过 withPodfile 给 Pod::Executable.execute_command 打 UTF-8 补丁；withDisableElegantTextHeight、withAndroidReleaseBuild、android-release.pro 控制发布行为。
所有插件以 TAG + generated 注释作为幂等锚点，避免重复注入；Gradle 变更通过正则匹配 allprojects.repositories 等精确位置插入，而非简单追加。

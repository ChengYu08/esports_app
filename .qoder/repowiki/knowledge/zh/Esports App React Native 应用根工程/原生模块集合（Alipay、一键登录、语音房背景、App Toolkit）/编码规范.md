- JS 层通过 `declare class XxxModule extends NativeModule<Events>` 声明原生接口，并使用 `requireOptionalNativeModule<XxxModule>('ModuleName')` 获取实例，以兼容 Expo Go 环境。
- 每个模块在顶层 `index.ts` 中以条件路径 `./src/XxxModule.web.ts` vs `./src/XxxModule.ts` 区分 Web 回退与原生实现，类型定义统一从 `.Types.ts` 或 `.types.ts` 重新导出。
- 模块元数据集中在 `expo-module.config.json` 中声明 platform 与 native module 全限定类名，供 Expo 构建时自动装配。

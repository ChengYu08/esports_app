本目录是多个相互独立的 Expo 原生模块的容器，每个子目录即一个可单独发布/集成的 native module，遵循 Expo Modules 规范：
- `alipay-payment`：Android 端通过 Kotlin 实现 `AlipayPaymentModule`，iOS 端缺失（未包含），JS 层以 `requireOptionalNativeModule('AlipayPayment')` 暴露 `payAsync` / `registerAppAsync`。
- `pz-one-click`：同时包含 Android Kotlin (`PzOneClickModule`) 与 iOS Swift (`PzOneClickModule.swift`)，并内嵌第三方 xcframework（ATAuthSDK、YTXMonitor、YTXOperators）；JS 侧声明事件泛型并通过 `requireOptionalNativeModule('PzOneClick')` 暴露一键登录能力。
- `voice-room-background`：Android 提供 Module + Service 双组件，iOS 提供 Swift Module，用于语音房后台任务处理。
- `expo-app-toolkit`：仅 Android 实现，提供 `canRequestPackageInstalls` 与流式 MD5 文件校验工具方法。

各模块 JS 入口统一通过 `expo-module.config.json` 注册 NativeModule 名称，并在顶层 `index.ts` 做平台条件重导出（`.web.ts` 回退）。所有模块使用 `requireOptionalNativeModule` 而非 `requireNativeModule`，以便在 Expo Go / 未 prebuild 构建中返回 null，由调用方自行降级。

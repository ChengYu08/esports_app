- 入口 `_layout.tsx` 通过 `expo-router` 的 `Tabs` + `Tabs.Protected` 声明式定义五个 tab：未受保护的 `index`、`ranking`，以及受 `useAuthStore` 鉴权守卫保护的 `order`、`message`、`mine`。
- 自定义 `tabBar` 由共享组件 `@/shared/ui/AppTabBar` 提供，`headerShown: false` 且禁用默认动画以规避 Expo Router 57 在 `detachInactiveScreens` 下的白屏问题。
- Android 平台通过 `BackHandler` 拦截物理返回键：若路由栈可回退则交由路由器处理，否则弹出 `AppPrompt` 确认退出应用。
- 各 tab 页面文件（`index.tsx`、`ranking.tsx`、`order.tsx`、`message.tsx`、`mine.tsx`）仅作为薄壳，渲染对应 feature 模块中的业务 Screen，依赖方向为 shell → features → shared，不持有跨 tab 状态。

采用 Expo Router 的文件路由约定：
- `index.tsx` 作为 `/match` 入口，直接导出 `MatchPublishScreen`，自身不实现 UI。
- `_layout.tsx` 定义该路由组的共享布局，使用 `expo-router` 的 `Stack` 导航器并统一关闭 header、设置淡入动画。
- `matching/[requestNo].tsx` 为动态参数路由，负责从 `useLocalSearchParams` 中解析 `requestNo`、`expireTime`、`gameId`、`gameName`、`gameIconUrl` 等查询参数，通过 `firstParam` 辅助函数处理数组/字符串兼容，再组合成 `MatchGame` 对象后交给 `MatchMatchingScreen`。
- 依赖方向单向向下：本模块仅做路由装配与参数清洗，UI 与 API 类型均位于 `@/features/match/*`，本模块不持有业务状态。

本目录是应用的路由聚合层，不承载业务逻辑：每个文件仅负责将自身 URL 路径转发到对应 Screen 组件，Screen 本身位于 `features/`、`shared/` 等目录。
- 基于 Expo Router 的页面：`(tabs)/`、`match/`、`chat/`、`voice-room/`、`activity/`、`club/`、`order/` 以及顶层平铺页面（如 `profile.tsx`、`login.tsx`、`web-view.tsx`），使用 Expo Router 的文件路由约定。
- 基于 Next.js App Router 的页面：`court/` 目录通过 `_layout.tsx` 挂载，独立于 Expo Router。
- `(tabs)/_layout.tsx` 与 `match/_layout.tsx` 为各自路由组的布局壳，分别处理底部标签导航和匹配页内布局；`_layout.tsx`（根）提供全局布局。
- 路由与业务解耦：URL → app 层文件 → Screen 组件 → services/store，app 层不持有状态。

本模块是 Next.js App Router 的路由壳，自身不实现业务逻辑，仅作为 URL → 组件的薄桥接层：
- `src/app/court/[id].tsx`、`complaint.tsx`、`reviewer.tsx`、`select-order.tsx`、`select-review.tsx`、`select-target.tsx` 以及 `ticket/[id].tsx` 均直接 `import` 并默认导出 `@/features/court/screens/` 下的对应 Screen 组件。
- 动态段 `[id]` 与嵌套目录 `ticket/[id]` 用于承载带参数的法庭详情与工单详情页面。
- 依赖方向单向：路由层 → `@/features/court/screens`，本模块不引入任何业务状态或 UI 实现，职责纯粹为路由分发。

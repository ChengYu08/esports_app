该模块是 Next.js App Router 的页面文件集合，每个 `.tsx` 仅承担路由职责：导入对应 `@/features/mine/screens` 下的 Screen 组件并默认导出，实现 URL 与业务页面的解耦。其中 `star-recharge.tsx` 是唯一包含逻辑的文件，通过 `Platform.OS` 在 Android 专用充值页 `StarRechargeAndroidScreen` 与通用 `StarRechargeScreen` 之间切换；其余文件（`companion-dashboard`、`companion-intro`、`companion-gallery`、`companion-income`、`my-diamonds`）均为纯重导出薄壳。依赖方向单向指向 `features/mine/screens`，本层不持有状态或业务逻辑。

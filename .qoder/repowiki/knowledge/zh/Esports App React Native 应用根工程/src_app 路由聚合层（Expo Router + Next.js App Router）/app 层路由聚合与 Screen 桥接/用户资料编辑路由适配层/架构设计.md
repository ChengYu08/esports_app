该模块为纯路由适配层，每个 .tsx 文件仅负责 import 对应 `@/features/mine/screens` 下的 Screen 组件并以默认导出暴露，自身不含业务逻辑。`profile.tsx` 暴露 ProfileScreen，`edit-profile.tsx` 暴露 EditProfileScreen，`avatar-crop.tsx` 暴露 AvatarCropScreen，`edit-nickname.tsx` 暴露 EditNicknameScreen，`edit-signature.tsx` 暴露 EditSignatureScreen，`profile-relations.tsx` 通过命名 re-export 暴露 ProfileRelationScreen。依赖方向单向指向 features 层，本模块不参与任何状态或网络交互。

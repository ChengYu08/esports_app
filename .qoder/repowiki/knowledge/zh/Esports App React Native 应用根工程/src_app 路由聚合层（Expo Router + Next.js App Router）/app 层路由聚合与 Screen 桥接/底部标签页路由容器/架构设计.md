- `_layout.tsx` 作为该路由组的入口，使用 `expo-router` 的 `<Tabs>` 组件声明五个屏幕：`index`（首页）、`ranking`、`order`、`message`、`mine`。
- 通过 `Tabs.Protected guard={isAuthenticated}` 将订单、消息、我的三个 Tab 包装为仅登录用户可见；未认证时隐藏对应 Tab 项。
- 自定义 `AppTabBar` 作为 tabBar 渲染器，并关闭 `detachInactiveScreens` 以规避 Expo Router 57 在快速切换时的白屏问题。
- Android 上监听 `hardwareBackPress`，当路由栈不可返回时弹出 `AppPrompt` 二次确认退出应用。
- 每个 Tab 页面文件（`index.tsx`、`ranking.tsx`、`order.tsx`、`message.tsx`、`mine.tsx`）仅做薄壳转发，实际 UI 由 `@/features/*/screens/*Screen` 提供，路由层不持有业务逻辑。
- 依赖方向单向向下：路由 → shared UI (`AppTabBar`、`AppPrompt`) / auth store (`useAuthStore`) → features 业务模块。

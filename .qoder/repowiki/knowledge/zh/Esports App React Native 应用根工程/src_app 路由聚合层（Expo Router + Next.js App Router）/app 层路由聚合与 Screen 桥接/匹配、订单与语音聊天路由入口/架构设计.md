本模块仅承担路由适配职责，本身不包含业务逻辑：
- `src/app/match/index.tsx` 通过别名导入 `@/features/match/screens/MatchPublishScreen` 作为匹配发布页；`_layout.tsx` 使用 `expo-router` 的 `Stack` 配置全局 `headerShown: false` 与 `animation: 'fade'`。
- `match/matching/[requestNo].tsx` 从 `useLocalSearchParams` 中解构 `requestNo/expireTime/gameId/gameName/gameIconUrl`，用本地 `firstParam` 处理数组型动态路由参数，并组装成 `MatchGame` 类型传给 `MatchMatchingScreen`。
- `order/[id].tsx` 把可选的 `scope` 查询串规范化为 `OrderScope`（`accept` 或默认 `place`）后交给 `OrderDetailScreen`；`order/dispatch/[requestNo].tsx` 直接透传 `requestNo` 到 `DispatchDetailScreen`。
- `voice-room/[id].tsx` 与 `chat/[id].tsx` 是更薄的路由壳，分别挂载 `VoiceRoomScreen` 和 `ChatScreen`。
依赖方向单向向外：路由层 → `@/features/*` 下的屏幕组件与类型定义，不反向引用。

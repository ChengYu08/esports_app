src/app 采用「路由薄壳 + 业务子目录」的扁平结构：每个 .tsx 文件仅负责解析 URL 参数并 render 对应 Screen 组件，实际 UI 逻辑位于 @/features 或 shared 包中。子模块按业务域划分（auth_flows / profile_editing / account_settings / companion_pages / activity_club_court / match_order_voice_chat / tab_routers / misc_utilities），由 (tabs) 路由组承载底部 Tab 导航，其余路由直接挂在 app 根级；各子模块之间不直接互相 import，跨页面通信通过全局状态或事件总线完成，路由层本身只承担路径到组件的单向委派。

该模块是 Expo Router 的路由表挂载点，每个文件对应一个 URL 路径：
- 绝大多数文件（search.tsx、report.tsx、protocol.tsx、about.tsx、web-view.tsx、message-notification.tsx）仅做单行 re-export，把 `@/features/*` 或 `@/shared/media-picker/MediaPickerScreen` 暴露给路由。
- image-preview.tsx 是唯一包含业务逻辑的文件：使用 `useLocalSearchParams` 解析路由参数，调用 `parseImagePreviewParams` 校验并渲染 `ImagePreview`，并在图片为空时通过 `router.back()` 返回。
依赖方向单向指向 `@/features`、`@/shared` 与 expo-router，本目录不持有状态或业务逻辑。

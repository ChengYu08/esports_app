本模块是 Expo Router 的顶层路由文件集合，每个 .tsx 对应一个页面：
- login.tsx：核心登录入口，通过 @esports/sso-sdk + createAuthSsoAdapter 接入运营商一键登录（含 checking/ready/fallback 三阶段探测），结合 completeClientLogin 完成会话建立；集成 CancellationCoolingDialog 处理账号注销冷却期；内置调试面板触发逻辑（连续点击顶部区域 7 次）。
- forgot-password.tsx / change-password.tsx：复用 features/auth 的 ForgotPasswordScreen，分别走“找回”和“修改”两条路径，改密成功后调用 signOut 清理旧会话。
- real-name-verification.tsx / account-cancellation.tsx：薄包装，直接默认导出 features/mine/screens 下的业务组件，无额外路由逻辑。
依赖方向单向向外：仅消费 @esports/auth、@esports/sso-sdk、@/features/*、@/core/config/env 等上层模块，不反向依赖业务状态。

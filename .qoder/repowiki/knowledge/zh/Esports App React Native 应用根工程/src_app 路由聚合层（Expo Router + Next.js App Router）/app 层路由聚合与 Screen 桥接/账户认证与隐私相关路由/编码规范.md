- SSO 客户端在组件内通过 useMemo 按 env.ssoClientSecret 是否存在条件构造 SsoClient，再经 createAuthSsoAdapter 生成 adapter，避免未配置时调用下游 API。
- 错误消息统一通过 getErrorMessage(error, fallback) 提取 error.message 并回退到中文提示，再通过 showToast 展示给用户。
- 需要隐藏导航头的页面在根元素内使用 <Stack.Screen options={{ headerShown: false }} /> 进行声明式配置。
- 平台差异化通过 Platform.OS === 'ios' ? 'iOS' : 'Android' 三元判断注入给 SsoClient 的 os/sourceType 字段。

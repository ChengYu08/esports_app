该模块是 Next.js App Router 的纯路由壳：每个文件仅做单一职责——从 `@/features/court/screens` 导入对应的 React 组件并默认导出，由框架根据文件名解析为页面。
- 动态路由 `[id].tsx` 对应 CourtDetailScreen，`ticket/[id].tsx` 对应 CourtTicketDetailScreen。
- 静态路由 `complaint.tsx`、`reviewer.tsx`、`select-order.tsx`、`select-review.tsx`、`select-target.tsx` 分别暴露 CourtComplaintScreen、CourtReviewerScreen、CourtOrderPickerScreen/CourtReviewPickerScreen、CourtTargetPickerScreen。
- 依赖方向单向指向 features 层，本目录不包含业务逻辑或样式，仅承担路由与组件别名转发。

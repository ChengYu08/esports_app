本模块是 Next/Expo Router 的文件级路由目录，自身不包含业务逻辑，仅做参数解析与转发：
- `src/app/activity/index.tsx`：处理 `/activity?activityCode=xxx` 通用落地页，通过 `useLocalSearchParams` 读取 activityCode，缺参时 Toast 提示并 `router.back()` 或 `router.replace("/")`，有效时渲染 `ActivityLandingScreen`；`rules.tsx` 为 `/activity/rules` 静态子路由，透传 rules HTML。
- `src/app/club/[id].tsx`：动态段路由，直接默认导出 `ClubDetailScreen`；`price-list.tsx` 对应 `/club/price-list` 静态子路由，导出 `PriceListScreen`。
依赖方向单向向外：路由层 → `@/features/*/screens/*`，不反向引用 features，也不引入 shared 工具（除 activity 落地页的 toast）。

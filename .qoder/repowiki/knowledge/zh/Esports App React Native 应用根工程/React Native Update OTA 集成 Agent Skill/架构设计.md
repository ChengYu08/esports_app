本模块采用 Agent Skills 标准布局，在 `.agents/skills/react-native-update/` 与 `agent/skills/react-native-update/` 两个镜像路径下各放置一份完整副本，供不同宿主或安装位置引用。
- `SKILL.md` 是主入口，使用 YAML front-matter 声明 name/description/compatibility，并在正文中定义服务路由（Pushy 中国 / Cresc 全球）、工作流（检测 → 阅读 playbook → 安装 → 配置原生加载 → 挂载 UpdateProvider → 运行 doctor → 发布验证）以及安全护栏（版本门槛、冷启动恢复、metaInfo 白名单校验、Hermes-base 等价性、禁用 expo-updates 冲突等）。
- `references/` 存放参考实现：`integration-playbook.md`、`modern-integration.md` 提供分步手册与现代集成快照；`rollout-whitelist.ts` 提供可复用的 metaInfo 白名单谓词。
- `scripts/integration_doctor.mjs` 是基于 Node.js 的静态诊断工具，通过 `spawnSync` 探测全局 pushy/cresc CLI、解析 `package.json`、递归扫描 JS/TS 与原生源码并匹配正则信号（UpdateProvider、new Pushy/Cresc、RCTPushy.bundleURL()、UpdateContext.getBundleUrl 等），输出结构化 JSON 报告（含 schema/appRoot/nativeBinaryVerified/checks/summary），支持 `--json`、`--strict`、`--help`。
- `scripts/integration_doctor.sh` 是对应 Bash 包装器。
- `agents/openai.yaml` 是可选的 OpenAI 主机元数据（display_name、short_description、default_prompt、policy.allow_implicit_invocation），不影响技能核心逻辑。
依赖方向单向：SKILL.md 引用 references 与 scripts；doctor 仅读取目标 app 文件，不反向依赖任何应用代码。

模块按能力域划分为独立子目录，每个子目录对外暴露一个稳定的 API 边界：
- `audio/`：基于 expo-audio 的 `useVoicePlayer` Hook，内部通过 `createAudioPlayer` + 事件订阅管理单例播放器，并提供纯函数 `nextVoicePlayback`（voice-player-state.mjs）供外部计算下一播放 URL。
- `media-picker/`：以 `media-picker-session.ts` 中的模块级 Promise resolver 实现「调用方 ↔ 媒体选择页」的单实例会话桥接，保证同一时刻仅一个 pending 会话。
- `ui/action-notice/`：基于 Zustand store (`action-notice-store.ts`) 维护最多 `ACTION_NOTICE_MAX_ITEMS=10` 条的通知栈，并通过 `handlersById` Map 绑定每行的 onDisappear 回调；`index.ts` 统一再导出。
- `navigation/`：集中处理标签页保护策略（`tab-access.ts` 用 Set 判断受保护 Tab 并返回 `TabPressAction`/`ProtectedNavigationAction` 联合类型），以及外链打开与登录拦截。
- `theme/`、`time/`、`hooks/`：分别提供设计令牌、服务器时间校准与下拉刷新 Hook。
依赖方向单向向外：本模块不反向依赖业务页面，仅被 App 各端引用；测试文件与源码同目录放置，后缀 `.test.tsx/.ts` 或 `.test.mjs` 对应 ES module。

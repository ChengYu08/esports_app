- 跨组件/跨页面的全局可变状态通过模块级变量（如 resolver、handlersById）+ 导出的 begin/complete 函数封装，而非直接暴露引用。
- UI 状态使用 Zustand 的 `create` 工厂创建 store，并通过 `getState()` / `setState()` 进行读写，测试时提供 `reset*Store` 清理入口。
- 对外 API 采用 barrel export（如 `ui/action-notice/index.ts`）聚合子模块导出，调用方只依赖 index 路径。
- 需要副作用的音频/网络操作封装为自定义 Hook（`useVoicePlayer`、`usePullToRefresh`），由调用组件在 `useEffect` 中释放资源。
- 枚举与受限取值通过 TypeScript 字面量联合类型表达（如 `AppTab`、`ProtectedDestination`、`TabPressAction`），并以纯函数做决策判定。

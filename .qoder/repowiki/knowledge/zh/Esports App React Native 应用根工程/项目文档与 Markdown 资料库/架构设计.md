该模块为纯文档仓库，不含可执行代码，按用途分为三层：
- `docs/architecture/`：顶层架构概览与模块依赖关系说明。
- `docs/superpowers/plans/` 与 `docs/superpowers/specs/`：以日期前缀命名的 Superpowers 迭代规划与设计规格，plans 侧重实现计划，specs 侧重界面/交互设计。
- `docs/rongcloud-offline-push-integration.md`：第三方服务（容云）离线推送集成说明。
- `md/`：面向具体业务模块（个人主页、俱乐部、订单、消息、陪玩下单、支付弹窗等）的需求、接口对接与实现说明，命名采用「主题 + 后缀」的中英混合风格（如 `*.md`、`*接口对接.md`、`*方案.md`）。
模块之间无代码依赖，仅作为团队共享的知识资产被其他模块引用或查阅。

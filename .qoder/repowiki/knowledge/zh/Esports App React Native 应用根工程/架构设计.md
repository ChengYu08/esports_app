以 `package.json` 中 `main: "expo-router/entry"` 作为 Expo 入口，由 `src/app` 将 URL 路由分发到 `src/features` 下的各业务域页面；所有子模块通过 pnpm workspace（`pnpm-workspace.yaml`）在 `packages/*` 下共享依赖，运行时依赖集中在根 `package.json` 统一管理。`app.config.js` 与 `eas.json` 在 Expo prebuild 阶段注入 CI 传入的版本号与 iOS buildNumber，并加载 `expo_plugins` 提供的自定义插件扩展原生配置；`native_modules` 中的原生 SDK 通过 autolinking 引入（排除 `expo-store-review`、`react-native-update`）。`build_scripts` 提供 `scripts/build_apk.cjs`、`scripts/with-env.cjs` 等根级脚本，统一处理 test/prod 环境切换、签名预检与 APK 打包；`shared_packages` 提供 @esports/sso-sdk 与 @esports/auth 认证层被上层 features 复用，`agent_skills` 与 `docs_and_md` 为协作文档与 OTA 集成指南。

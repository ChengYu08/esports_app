模块由两个独立的 npm 子包组成，依赖方向单向：auth → sso-sdk。
- packages/sso-sdk：纯 JS/TS 网络层，`src/client.ts` 暴露 `SsoClient` 类，基于 axios 封装请求、时间戳对齐（通过 `/api/server/time` 计算 server-time 偏移并缓存）、MD5 签名（`signature.ts` + `md5.ts`）与错误类型（`types.ts`），并通过 `password-requests.ts` 组装密码登录/忘记密码请求体；`native-quick-login.ts` 暴露原生快捷登录 Provider 工厂；所有 API 经 `src/index.ts` 聚合导出。
- packages/auth：React Native UI 与业务适配层，`LoginScreen.tsx` / `ForgotPasswordScreen.tsx` 为页面组件，`auth-store.ts` 用 zustand 管理会话状态，`sso-adapter.ts` 将 `@esports/sso-sdk` 的 `SsoClient` 方法映射为应用侧的 `sendCode/login/passwordLogin/forgetPassword/quickLogin` 等统一接口，`password-validation.ts` 提供手机号、验证码、密码的 sanitize/validate 工具函数，全部从 `src/index.ts` 重新导出。
- 两个包均声明 `main`/`types`/`exports` 指向 `./src/index.ts`，且均为 `private: true`，仅作为应用内共享依赖使用。

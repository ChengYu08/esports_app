- 每个包通过 `package.json` 的 `main`、`types`、`exports` 三个字段同时指向 `./src/index.ts`，实现单入口导出。
- 对外 API 集中在 `src/index.ts` 中按职责分组 re-export，UI 组件导出具体类型（如 `LoginScreenProps`、`ForgotPasswordFormValues`），工具函数直接导出。
- SSO 网络调用统一经由 `SsoClient.request`，先同步服务端时间偏移再计算签名，并以 `SsoError` 抛出业务异常，HTTP 状态码 <200 或 ≥300 一律视为失败。
- 表单输入在提交前通过 `sanitizePhone`/`sanitizeCode` 等工具去非数字字符，再由 `validate*` 系列函数返回 null 表示合法、字符串表示错误提示。

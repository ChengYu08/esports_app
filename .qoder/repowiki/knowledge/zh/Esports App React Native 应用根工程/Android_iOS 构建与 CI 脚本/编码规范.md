- 每个可执行脚本都同时提供 Node (`*.cjs`) 与 bash (`*.sh`) 两种实现，保证 Windows/macOS/Linux 行为一致。
- CLI 参数采用短横线前缀的键值对解析（如 `--abi`、`--env`、`--init-signing`），非法参数打印 usage 后 `process.exit(1)`。
- 构建产物统一通过 `archive-apk.cjs` 归档，文件名遵循 `应用名称-版本号-架构标签-年月日时分.apk` 的命名约定。
- 敏感签名材料（keystore、credentials、证书）存放在工程目录之外的独立文件夹（`.android-signing/`、`signing/certs/`、`signing/profiles/`）并加入 `.gitignore`，避免提交。
- CI 相关脚本通过环境变量驱动行为（如 `REACT_NATIVE_ARCHITECTURES`、`DRONE_ABI`、`DEVELOPMENT_TEAM`），并提供 `secrets.example.env` 模板供开发者参考。

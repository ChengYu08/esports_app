Android：`npm run build:apk[:arm64|universal|all]` 或 `node scripts/build_apk.cjs --abi arm64|universal|all [--env prod|test]`，首次运行 `--init-signing` 生成 `.android-signing/release.keystore`；iOS：将 `.p12` 与 `.mobileprovision` 放入 `ci/github-actions/ios-build/signing/{certs,profiles}/` 后执行 `./ci/github-actions/ios-build/signing/scripts/print-secrets.sh [--apply]` 生成 secrets 并推送至 GitHub。

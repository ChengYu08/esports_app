模块按平台划分为两个相对独立的子目录：
- `scripts/`：Android 构建工具集，以 `build_apk.cjs`（Node）和 `build_apk.sh`（bash）为双实现入口，分别通过 npm scripts (`npm run build:apk*`) 或直接调用；核心流程包括：清理并删除 `android/`、启动 Gradle/Kotlin daemon 守护进程、执行 Expo prebuild + release 构建、启用 R8 混淆与资源裁剪、调用 `archive-apk.cjs` 输出命名化的 APK 到 `apks/` 目录，并通过 `android-signing.cjs` 管理 `.android-signing/` 下的 PKCS12 keystore 与 `credentials.json`。
- `ci/github-actions/ios-build/`：由 `ipa-cli actions init-ios-build` 生成的 iOS 构建模板，包含 workflow 说明、`secrets.example.env` 模板以及 `signing/scripts/preflight-ios-build.sh`（本地预检）、`print-secrets.sh`（从 `.p12` / `.mobileprovision` 生成 secrets 或写入 GitHub CLI）。该目录仅作为配置模板存在，不直接参与本机构建。
依赖方向单向：workflow 触发 Node/npm/CocoaPods/xcodebuild 链式步骤，脚本之间通过命令行参数与环境变量（如 `REACT_NATIVE_ARCHITECTURES`、`APK_ABI_LABEL`）通信，无相互 require。

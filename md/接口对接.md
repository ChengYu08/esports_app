# 接口对接

## 后端服务

- 服务代码：`/Users/yucheng/Desktop/盼之电竞/pzdj-service`
- 当前可用 API 域名：`https://djapi.yingbowl.com`
- C 端接口统一前缀：`/client/v1`
- 移动端环境变量：`EXPO_PUBLIC_API_BASE_URL=https://djapi.yingbowl.com`

> 不要再使用 `api-cb.yingbowl.com`：该域名公网请求会被 Nginx 返回 `403`。
> `djapi.yingbowl.com` 可访问内网服务，路径不需要再拼接 `/api/dj`。

## 已验证接口

`POST https://djapi.yingbowl.com/client/v1/companion/public/page`

请求示例：

```json
{
  "page": 1,
  "pageSize": 10,
  "action": {
    "clubId": 1,
    "gameId": 4,
    "sex": 0
  }
}
```

实测返回 HTTP `200`：

```json
{
  "success": true,
  "code": "SUCCESS",
  "info": "操作成功",
  "data": {
    "page": 1,
    "totalPages": 0,
    "total": 0,
    "records": []
  }
}
```

接口路由和请求参数均正常；当前筛选条件下没有匹配的陪玩数据，因此 `records` 为空。

## 登录对接

统一登录成功后，使用 SSO 返回的 `id_token` 调用 `pzdj-service` 的 C 端公开接口换取业务 token：

`POST https://djapi.yingbowl.com/client/v1/user/public/login/idtoken`

请求体：

```json
{
  "action": {
    "idToken": "<SSO 返回的 id_token>",
    "registerWay": "SMS_CODE"
  }
}
```

返回的 `data.token` 是 C 端业务 token，不是 SSO 的 `access_token`。

拿到业务 token 后，获取当前登录用户资料：

`POST https://djapi.yingbowl.com/client/v1/user/login/info`

请求头：

```text
Content-Type: application/json
token: <data.token>
```

资料响应主要字段包括：`id`、`nickname`、`headImage`、`phone`、`gender`、`birth`、`signature`、`isRealName`、`clubInfo`、`positions`、`starBalance`。

后续需要登录态的 C 端接口统一携带 `token` 请求头。公开接口（路径包含 `/public/`）无需业务 token。

## 页面定位

- 本页面为移动端 Expo 页面，以 375 × 812 设计稿为基准。
- 不实现设计稿最顶部的系统状态栏（时间、Wi-Fi、电量等）。
- 静态资源使用项目内自动切图生成的资源；不依赖 Figma MCP 返回的临时资源链接。

## 页面结构

1. 顶部导航：`首页`、`小法庭` 和右侧搜索入口。
   - `首页`、`小法庭` 是可切换的顶部 Tab。
   - 首页为默认选中态。
   - 切换到小法庭时，本期先展示空白占位页面；小法庭具体功能后续补充。
   - 搜索入口本期需要实现；具体搜索页 UI 后续补充。
2. Banner：展示当前顶部 Tab 对应的运营推广内容。
   - Banner 素材多张时自动轮播。
   - Banner 只有一张时固定展示，不进行轮播。
3. 游戏切换：`三角洲端游`、`三角洲手游`。
4. 热门俱乐部：标题右侧保留筛选入口。
   - 筛选入口本期需要实现；具体筛选 UI 后续补充。
5. 俱乐部列表：展示俱乐部封面、自营标签（如有）、名称、在线人数、介绍、成员数和 ID。
6. 底部导航：`首页`、`订单`、`消息`、`我的`；中间展示红色闪电主操作按钮。
   - 首页内容允许游客浏览。
   - 订单、消息、我的等其他底部入口需要登录后访问。
   - 红色闪电按钮是快速匹配入口，点击后进入二级匹配页面。
   - 匹配页面本期先展示空白占位页面，具体 UI 和流程后续补充。

## 交互与数据

### 游戏切换

- 默认展示三角洲端游。
- 点击端游或手游时，更新对应 Tab 的选中样式。
- 切换游戏时，热门俱乐部内容必须切换为该游戏对应的数据，并重新从第一页加载。

### 顶部 Tab 切换

- 默认进入首页 Tab。
- 点击首页或小法庭时，更新顶部 Tab 的选中样式，并切换对应的页面内容。
- 首页内容包含 Banner、游戏选择 Tab 和热门俱乐部列表。
- 小法庭本期仅展示空白占位页面，具体内容以后续 UI 和需求为准。

### Banner

- 当前顶部 Tab 对应的 Banner 数据独立维护。
- Banner 数据数量大于 1 时启用轮播。
- Banner 数据数量等于 1 时固定展示单张图片。
- Banner 数据来源、运营配置、缓存策略和加载失败兜底方式待后续补充。

### 俱乐部列表

- 热门俱乐部列表支持纵向滚动。
- 支持下拉刷新：刷新当前顶部 Tab、当前游戏下的列表，并回到第一页。
- 支持上拉分页：滚动接近底部时加载下一页；无更多数据时停止加载。
- 列表数据通过接口获取。
- 俱乐部图片由接口返回，图片兜底策略待后续补充。
- 列表加载中、空列表、请求失败、重试和网络异常等状态的具体 UI 待后续补充。
- 点击俱乐部的详情跳转暂不实现，等待后续详情页 UI。

### 其他入口

- 顶部搜索、筛选入口的具体交互和页面形态待后续补充。
- 底部订单、消息、我的页面及登录后的具体流程待后续页面 UI 补充。
- 红色闪电按钮进入二级匹配页面；匹配页面本期使用空白占位。

# iOS / Android 后台语聊房完整方案

> **背景**：App Store 第二次拒稿（准则 2.5.4），原因是 `Info.plist` 声明了 `UIBackgroundModes: ["audio"]`，但审核员在 iPad Air (M3) 上找不到需要持续后台音频的功能。
>
> **目标**：
> - **iOS**：真正实现后台语聊房音频播放，并让审核员能直观看到（锁屏/控制中心出现"正在播放"卡片），从而通过审核
> - **Android**：完善现有前台服务，改用 MediaStyle 通知、支持实时麦克风状态同步、添加"结束语聊"action
>
> **提交 ID**：cc1295fc-fe01-48cf-bbaa-49f47129f46a
> **审核日期**：2026-10-20
> **审核版本**：1.0 (11)

### 关键问题

**iOS 端**:
1. `src/features/voice-room/voice-room-background.ts` 第 9 行：`Platform.OS !== 'android'` 时直接 `return null`，**iOS 上完全不执行任何后台逻辑**
2. `modules/voice-room-background/` 下**只有 `android` 目录，没有 `ios`**
3. 没有任何代码调用 `AVAudioSession.setCategory` 或 `MPNowPlayingInfoCenter`

**Android 端**:
1. 通知是普通 `Notification`，未用 `MediaStyle`，锁屏展示不突出
2. 模块只有 `start` / `stop`，缺 `updateMicrophone`，切换麦克风状态时通知不会实时刷新
3. 通知没有"结束语聊"action，用户无法在通知栏直接退出

### iOS 与 Android 的核心差异

| 平台 | 后台音频时回到 app 的入口 | 实现方式 |
|---|---|---|
| Android | ✅ 通知栏常驻通知（MediaStyle） | 应用启动前台服务（已实现，需美化） |
| iOS 控制中心 | ⚠️ 系统"正在播放"卡片 | 需接入 `MPNowPlayingInfoCenter`（**未实现** ❌） |
| iOS 锁屏 | ⚠️ 同上 | 需接入 `MPNowPlayingInfoCenter` + `MPRemoteCommandCenter`（**未实现** ❌） |
| iOS 下拉通知中心 | ❌ 永远没有常驻入口 | iOS 系统设计如此，无法实现 |

**结论**：iOS 用户切后台后回到语聊房的方式只能是 ① 点 app 图标 ② 控制中心/锁屏的"正在播放"卡片 ③ 灵动岛。当前项目这三者都不具备。

#### `ios/VoiceRoomBackgroundModule.swift`

```swift
import ExpoModulesCore
import AVFoundation
import MediaPlayer

public class VoiceRoomBackgroundModule: Module {
  public func definition() -> ModuleDefinition {
    Name("VoiceRoomBackground")

    AsyncFunction("start") { (title: String, microphoneEnabled: Bool) in
      try self.activateAudioSession()
      self.updateNowPlaying(title: title, isPlaying: true, micEnabled: microphoneEnabled)
      self.registerRemoteCommands()
    }.runOnQueue(.main)

    AsyncFunction("stop") {
      self.clearNowPlaying()
      try? self.deactivateAudioSession()
    }.runOnQueue(.main)

    AsyncFunction("updateMicrophone") { (enabled: Bool) in
      var info = MPNowPlayingInfoCenter.default().nowPlayingInfo ?? [:]
      info[MPMediaItemPropertyTitle] = enabled ? "语聊房（说话中）" : "语聊房（听筒中）"
      MPNowPlayingInfoCenter.default().nowPlayingInfo = info
    }.runOnQueue(.main)
  }

  private func activateAudioSession() throws {
    let session = AVAudioSession.sharedInstance()
    // 使用 .mixWithOthers 避免与 Agora 内部的 session 操作冲突
    try session.setCategory(
      .playAndRecord,
      mode: .voiceChat,
      options: [.defaultToSpeaker, .allowBluetooth, .mixWithOthers]
    )
    try session.setActive(true, options: [])
  }

  private func deactivateAudioSession() throws {
    let session = AVAudioSession.sharedInstance()
    try session.setActive(false, options: [.notifyOthersOnDeactivation])
  }

  private func updateNowPlaying(title: String, isPlaying: Bool, micEnabled: Bool) {
    var info: [String: Any] = [
      MPMediaItemPropertyTitle: micEnabled ? "\(title)（说话中）" : title,
      MPMediaItemPropertyArtist: "盼之电竞 · 语聊房",
      MPMediaItemPropertyAlbumTitle: "实时语音通话",
      MPNowPlayingInfoPropertyIsLiveStream: true,
      MPNowPlayingInfoPropertyPlaybackRate: isPlaying ? 1.0 : 0.0,
    ]
    if let image = UIImage(named: "AppIcon") {
      let artwork = MPMediaItemArtwork(boundsSize: image.size) { _ in image }
      info[MPMediaItemPropertyArtwork] = artwork
    }
    MPNowPlayingInfoCenter.default().nowPlayingInfo = info
    MPNowPlayingInfoCenter.default().playbackState = isPlaying ? .playing : .paused
  }

  private func clearNowPlaying() {
    MPNowPlayingInfoCenter.default().nowPlayingInfo = nil
    MPNowPlayingInfoCenter.default().playbackState = .stopped
    let center = MPRemoteCommandCenter.shared()
    center.playCommand.removeTarget(nil)
    center.pauseCommand.removeTarget(nil)
    center.togglePlayPauseCommand.removeTarget(nil)
  }

  private func registerRemoteCommands() {
    let center = MPRemoteCommandCenter.shared()
    center.togglePlayPauseCommand.isEnabled = true
    center.togglePlayPauseCommand.addTarget { _ in .success }
    // 语聊房场景禁用上一首/下一首/进度条
    center.previousTrackCommand.isEnabled = false
    center.nextTrackCommand.isEnabled = false
    center.changePlaybackPositionCommand.isEnabled = false
  }
}
```

### 步骤 1B：Android — 完善现有前台服务

目标：让 Android 通知具备与 iOS 锁屏卡片对等的体验 —— MediaStyle、实时麦克风状态、结束 action。

#### `VoiceRoomBackgroundService.kt` 完整重写

```kotlin
package expo.modules.voiceroombackground

import android.app.Notification
import android.app.NotificationChannel
import android.app.NotificationManager
import android.app.PendingIntent
import android.app.Service
import android.content.Intent
import android.content.pm.ServiceInfo
import android.os.Build
import android.os.IBinder

class VoiceRoomBackgroundService : Service() {
  override fun onBind(intent: Intent?): IBinder? = null

  override fun onStartCommand(intent: Intent?, flags: Int, startId: Int): Int {
    // 处理"结束语聊" action
    if (intent?.action == ACTION_STOP) {
      if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.N) {
        stopForeground(STOP_FOREGROUND_REMOVE)
      } else {
        @Suppress("DEPRECATION")
        stopForeground(true)
      }
      stopSelf()
      return START_NOT_STICKY
    }

    val title = intent?.getStringExtra(EXTRA_TITLE) ?: "语聊房进行中"
    val microphoneEnabled = intent?.getBooleanExtra(EXTRA_MICROPHONE_ENABLED, false) ?: false
    val updateOnly = intent?.getBooleanExtra(EXTRA_UPDATE_ONLY, false) ?: false

    createNotificationChannel()

    if (updateOnly) {
      // 只刷新通知，不重复 startForeground
      val manager = getSystemService(NotificationManager::class.java)
      manager.notify(NOTIFICATION_ID, buildNotification(title, microphoneEnabled))
    } else {
      // 首次启动前台服务
      if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.Q) {
        var serviceType = ServiceInfo.FOREGROUND_SERVICE_TYPE_MEDIA_PLAYBACK
        if (microphoneEnabled) {
          serviceType = serviceType or ServiceInfo.FOREGROUND_SERVICE_TYPE_MICROPHONE
        }
        startForeground(NOTIFICATION_ID, buildNotification(title, microphoneEnabled), serviceType)
      } else {
        startForeground(NOTIFICATION_ID, buildNotification(title, microphoneEnabled))
      }
    }
    return START_STICKY
  }

  private fun createNotificationChannel() {
    if (Build.VERSION.SDK_INT < Build.VERSION_CODES.O) return
    val manager = getSystemService(NotificationManager::class.java)
    manager.createNotificationChannel(
      NotificationChannel(CHANNEL_ID, "语聊房", NotificationManager.IMPORTANCE_LOW).apply {
        description = "语聊房通话进行时显示"
      },
    )
  }

  private fun buildNotification(title: String, microphoneEnabled: Boolean): Notification {
    // 点击通知 → 回到 app
    val launchIntent = packageManager.getLaunchIntentForPackage(packageName)
    val contentPendingIntent = launchIntent?.let {
      PendingIntent.getActivity(
        this, 0, it,
        PendingIntent.FLAG_UPDATE_CURRENT or
          if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.M) PendingIntent.FLAG_IMMUTABLE else 0,
      )
    }

    // "结束语聊" action
    val stopIntent = Intent(this, VoiceRoomBackgroundService::class.java).apply {
      action = ACTION_STOP
    }
    val stopPendingIntent = PendingIntent.getService(
      this, 1, stopIntent,
      PendingIntent.FLAG_UPDATE_CURRENT or
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.M) PendingIntent.FLAG_IMMUTABLE else 0,
    )

    val builder = if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
      Notification.Builder(this, CHANNEL_ID)
    } else {
      @Suppress("DEPRECATION")
      Notification.Builder(this)
    }

    builder
      .setSmallIcon(android.R.drawable.ic_btn_speak_now)
      .setContentTitle(if (microphoneEnabled) "$title（说话中）" else title)
      .setContentText("语音连接正在后台保持")
      .setCategory(Notification.CATEGORY_CALL)
      .setOngoing(true)
      .setContentIntent(contentPendingIntent)
      .addAction(
        Notification.Action.Builder(null, "结束语聊", stopPendingIntent).build(),
      )
      // MediaStyle 让通知在锁屏和通知栏更突出
      .setStyle(Notification.MediaStyle().setShowActionsInCompactView(0))

    return builder.build()
  }

  companion object {
    const val EXTRA_TITLE = "voiceRoomTitle"
    const val EXTRA_MICROPHONE_ENABLED = "microphoneEnabled"
    const val EXTRA_UPDATE_ONLY = "updateOnly"
    const val ACTION_STOP = "expo.modules.voiceroombackground.ACTION_STOP"
    private const val CHANNEL_ID = "voice-room-audio"
    private const val NOTIFICATION_ID = 5701
  }
}
```

#### `VoiceRoomBackgroundModule.kt` 新增 `updateMicrophone`

```kotlin
package expo.modules.voiceroombackground

import android.content.Intent
import android.os.Build
import expo.modules.kotlin.modules.Module
import expo.modules.kotlin.modules.ModuleDefinition

class VoiceRoomBackgroundModule : Module() {
  override fun definition() = ModuleDefinition {
    Name("VoiceRoomBackground")

    AsyncFunction("start") { title: String, microphoneEnabled: Boolean ->
      val context = appContext.reactContext?.applicationContext
        ?: throw IllegalStateException("语聊房后台服务不可用")
      val intent = Intent(context, VoiceRoomBackgroundService::class.java)
        .putExtra(VoiceRoomBackgroundService.EXTRA_TITLE, title)
        .putExtra(VoiceRoomBackgroundService.EXTRA_MICROPHONE_ENABLED, microphoneEnabled)
      if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) context.startForegroundService(intent)
      else context.startService(intent)
      null
    }.runOnQueue(expo.modules.kotlin.functions.Queues.MAIN)

    AsyncFunction("stop") {
      val context = appContext.reactContext?.applicationContext
      if (context != null) {
        context.stopService(Intent(context, VoiceRoomBackgroundService::class.java))
      }
      null
    }.runOnQueue(expo.modules.kotlin.functions.Queues.MAIN)

    // 新增：实时同步麦克风状态
    AsyncFunction("updateMicrophone") { enabled: Boolean ->
      val context = appContext.reactContext?.applicationContext
        ?: throw IllegalStateException("语聊房后台服务不可用")
      val intent = Intent(context, VoiceRoomBackgroundService::class.java)
        .putExtra(VoiceRoomBackgroundService.EXTRA_TITLE, "语聊房进行中")
        .putExtra(VoiceRoomBackgroundService.EXTRA_MICROPHONE_ENABLED, enabled)
        .putExtra(VoiceRoomBackgroundService.EXTRA_UPDATE_ONLY, true)
      context.startService(intent)
      null
    }.runOnQueue(expo.modules.kotlin.functions.Queues.MAIN)
  }
}
```

### 步骤 2：修改 `src/features/voice-room/voice-room-background.ts`

**当前实现（iOS 直接 return null）**:

```typescript
function getModule() {
  if (Platform.OS !== 'android') return null;   // ← 问题所在
  try {
    const { requireNativeModule } = require('expo-modules-core');
    return requireNativeModule<VoiceRoomBackgroundModule>('VoiceRoomBackground');
  } catch {
    return null;
  }
}
```

**修改为（iOS/Android 都走原生模块）**:

```typescript
import { Platform } from 'react-native';

type VoiceRoomBackgroundModule = {
  start: (title: string, microphoneEnabled: boolean) => Promise<void>;
  stop: () => Promise<void>;
  updateMicrophone?: (enabled: boolean) => Promise<void>;
};

let cachedModule: VoiceRoomBackgroundModule | null | undefined;

function getModule() {
  if (cachedModule !== undefined) return cachedModule;
  try {
    // eslint-disable-next-line @typescript-eslint/no-require-imports
    const { requireNativeModule } = require('expo-modules-core') as typeof import('expo-modules-core');
    cachedModule = requireNativeModule<VoiceRoomBackgroundModule>('VoiceRoomBackground');
  } catch {
    cachedModule = null;
  }
  return cachedModule;
}

export async function startVoiceRoomBackground(microphoneEnabled: boolean) {
  const module = getModule();
  if (!module) return;
  try {
    await module.start('语聊房进行中', microphoneEnabled);
  } catch (error) {
    console.warn('[voice-room] background service start failed', error);
  }
}

export async function stopVoiceRoomBackground() {
  const module = getModule();
  if (!module) return;
  try {
    await module.stop();
  } catch (error) {
    console.warn('[voice-room] background service stop failed', error);
  }
}

export async function updateVoiceRoomMicrophone(enabled: boolean) {
  const module = getModule();
  if (!module?.updateMicrophone) return;
  try {
    await module.updateMicrophone(enabled);
  } catch (error) {
    console.warn('[voice-room] update microphone state failed', error);
  }
}
```

```typescript
export function muteVoiceRtc(muted: boolean) {
  if (!engine) return -1;
  const result = engine.updateChannelMediaOptions({
    autoSubscribeAudio: true,
    publishMicrophoneTrack: !muted,
  });
  if (result !== 0) return result;
  const muteResult = engine.muteLocalAudioStream(muted);
  if (muteResult === 0) {
    useVoiceRoomSessionStore.getState().setMicrophoneMuted(muted);
    void startVoiceRoomBackground(!muted);
    void updateVoiceRoomMicrophone(!muted);   // ← 新增
  }
  return muteResult;
}
```

```
  必须继续 —— 包括其他参与者语音的播放和用户自己的麦克风。
  这是所有语音通话类应用的标准和预期行为；没有它，用户离开
  房间界面通话就会被中断。

我们已在「App 审核信息 → 备注」附件中上传真机录屏
（background-audio-demo.mp4），演示了：

  1. 进入语聊房，有另一位参与者正在说话
  2. 切回主屏幕 —— 音频持续可听
  3. 锁屏 —— 音频继续，且锁屏/控制中心显示"语聊房进行中"
     的正在播放卡片
  4. 解锁回到 app —— 语聊房会话完好

真机验证步骤：
  1. 登录并加入任一语聊房（首页 → 任一俱乐部 → 语聊房）
  2. 让另一位参与者（或第二台设备）在房间中说话
  3. 按 Home 键/上滑 —— 音频继续
  4. 打开控制中心或锁屏 —— 出现带房间标题的"正在播放"卡片

Info.plist 中的相关声明：
  - UIBackgroundModes: ["audio"]
  - NSMicrophoneUsageDescription: "用于在语聊房中进行语音交流。"

如需任何补充信息，请随时告知。
```

## 五、风险与注意事项

| 风险 | 应对 |
|---|---|
| Agora 与 `setCategory` 冲突（iOS） | 使用 `.mixWithOthers` 选项；如仍冲突，把 session 激活放在 `engine.enableAudio()` 之后 |
| 控制中心不显示卡片（iOS） | 检查 `MPNowPlayingInfoPropertyPlaybackRate` 是否为 1.0；iOS 16+ 需要 `playbackState = .playing` |
| 审核员没找到语聊房入口 | 在 App Review Information 备注里写清楚路径（首页 → 任一俱乐部 → 语聊房） |
| 审核员测试时房间没人说话 | 提供一个测试账号 + 测试房间号；或在备注里告知审核员"请联系我们开启测试房间" |
| `expo-audio` 插件与 AVAudioSession 冲突（iOS） | 当前 `app.json:50` `enableBackgroundPlayback: false`，不冲突；如未来开启需重新评估 |
| 模拟器测试 | **不支持**，必须真机 |
| `prebuild --clean` 会清空 `ios/` 和 `android/` 目录 | 已加入 `.gitignore`，无需担心；如有手动修改需提前备份 |
| Android 14+ 前台服务限制 | 已在 `withVoiceRoomBackground.js` 中声明 `FOREGROUND_SERVICE_MEDIA_PLAYBACK` 和 `FOREGROUND_SERVICE_MICROPHONE`，✅ 满足 Android 14 要求 |
| Android 13+ 通知权限 | 已声明 `POST_NOTIFICATIONS`；用户首次进入语聊房需授予通知权限，否则看不到常驻通知（不影响音频功能） |
| Android 厂商杀后台 | 小米/华为/OPPO 等可能限制前台服务，建议引导用户开启"自启动"和"电池无限制"（非阻塞问题） |

## 八、备用方案（如实现受阻）

如果 iOS 原生模块实现遇到阻碍，**退路是从 `UIBackgroundModes` 中移除 `audio`**：

```diff
// app.json
"ios": {
  "supportsTablet": false,
  "bundleIdentifier": "com.esportsapp.apps",
  "infoPlist": {
-   "UIBackgroundModes": ["audio"],
    "NSMicrophoneUsageDescription": "用于在语聊房中进行语音交流。"
  }
}
```

**代价**：用户切后台后语聊房音频中断，体验下降，但能通过审核。

**判断标准**：如果步骤 1-3 在 1 个工作日内无法完成真机验证，建议先采用备用方案上架，后续版本再补回。

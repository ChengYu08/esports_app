# 消息 Tab 页面设计

## 目标

依据 `md/消息tab.md` 指定的 Figma 节点 `13:8692`，在现有 Expo Router Tab 结构中实现消息列表页面。页面需适配 iOS 与 Android，并为后续接入真实会话接口保留清晰的数据边界。

## 范围

本次实现包含：

- 消息页顶部操作区。
- 系统通知与四条示例会话列表。
- Figma 中使用的清空、搜索、系统通知和头像 SVG 资源。
- 列表项的可访问点击区域与基础按压反馈。
- 安全区、长文本截断和不同屏幕宽度适配。

本次不包含：

- 聊天详情页、系统通知详情页或相应路由。
- 后端接口、实时通信、未读数同步或持久化。
- Figma 手机状态栏和重复的底部导航栏；运行时分别由系统和现有 `AppTabBar` 提供。

## 页面结构

`src/app/(tabs)/message.tsx` 继续作为路由入口，只渲染消息功能模块中的 `MessageScreen`。业务 UI 放在 `src/features/message/`：

- `screens/MessageScreen.tsx`：安全区、页面背景、顶部栏和列表编排。
- `components/MessageHeader.tsx`：页面标题、清空和搜索操作区。
- `components/MessageListItem.tsx`：头像、标题、时间、摘要和分割线。
- `message.types.ts`：页面展示模型。
- `message.data.ts`：与 Figma 一致的本地示例数据。

资源统一放在 `assets/message/`，由组件静态 `require`，避免运行时网络依赖。

## 视觉还原

- 页面背景使用 `#F7F7F7`，顶部和消息列表使用白色。
- 顶部栏高度 44，遵循设备顶部安全区；不绘制 Figma 的模拟状态栏。
- 每条消息使用 16 像素内边距、40×40 头像、12 像素横向间距。
- 标题为 14 像素半粗体、`#333333`；时间为 12 像素、`#CCCCCC`；摘要为 14 像素、`#999999`。
- 列表分割线从文本区域起始位置绘制，颜色 `#EBEBEB`、视觉厚度约 0.5 像素；最后一项无分割线。
- 摘要限制为一行并省略溢出内容，防止窄屏破坏布局。

## 数据与交互

页面使用只读展示模型描述 `id`、类型、标题、摘要、时间和头像资源。系统通知使用独立图标样式，普通会话使用 Figma 导出的头像。

顶部和列表项均使用 `Pressable`：

- 左侧显示一级 Tab 标题“消息”，不提供返回按钮。
- 清空、搜索和列表点击暂不绑定虚构业务，仅保留明确的组件回调边界。
- 所有图标按钮提供中文无障碍标签，点击区域不小于 44×44。

## 性能与兼容性

消息列表使用 `FlatList`，数据和资源映射定义在组件外，列表项组件保持职责单一。静态 SVG 通过项目已有的 `expo-image` 渲染，不新增依赖。布局只使用 React Native 跨平台样式，不依赖原生目录改动。

## 错误与降级

静态资源随包发布，不涉及网络错误。若未来数据为空，页面主体保持背景色并可增补空态；本次按 Figma 展示固定示例数据。

## 验证

- 运行 `npm run lint`。
- 运行 `npx tsc --noEmit`。
- 检查 375 像素设计宽度下的间距、字号、颜色和截断行为。
- 检查更窄和更宽屏幕下标题、时间及摘要不重叠。
- 检查 iOS 与 Android 顶部安全区及现有底部 TabBar 不被重复渲染。

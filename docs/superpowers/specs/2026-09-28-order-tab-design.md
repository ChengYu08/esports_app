# 订单 Tab 页面设计

## 目标

依据 `md/订单tab.md` 指定的 Figma 节点 `13:7155`，在现有 Expo Router Tab 结构中实现订单中心页面。页面优先保证移动端还原、跨平台布局和后续接口接入时的可维护性。

## 范围

本次实现包含：

- 左侧标题为“订单”的一级 Tab 顶部栏，不显示返回图标。
- 全部、进行中、已完成、已取消四个订单筛选项。
- 待支付、已支付、已完成三种示例订单卡片。
- 与 Figma 一致的卖家头像 SVG 资源。
- 订单状态、价格、数量、实付金额和对应操作按钮样式。
- 本地筛选、空态、按压反馈和无障碍标签。
- 安全区、滚动区域和不同屏幕宽度适配。

本次不包含：

- 订单详情页和详情路由。
- 真实订单接口、支付、取消、售后、评价或再次下单业务。
- Figma 模拟状态栏、Home Indicator 和重复底部导航栏；运行时由系统与现有 `AppTabBar` 提供。

## 页面结构

`src/app/(tabs)/order.tsx` 继续作为轻量路由入口，只渲染 `OrderScreen`。业务 UI 放在 `src/features/order/`：

- `screens/OrderScreen.tsx`：安全区、当前筛选状态、列表与空态编排。
- `components/OrderHeader.tsx`：左侧一级页面标题“订单”。
- `components/OrderTabs.tsx`：四个筛选项及选中指示线。
- `components/OrderCard.tsx`：订单信息、状态和操作按钮。
- `order.types.ts`：筛选值、订单状态、操作项和订单展示模型。
- `order.data.ts`：与 Figma 一致的本地示例数据。

静态资源统一放在 `assets/order/`，通过 `expo-image` 和静态 `require()` 渲染。

## 视觉还原

- 页面背景使用 `#F7F7F7`；顶部栏、筛选栏与订单卡使用白色。
- 顶部栏高度 44，左侧内边距 16；标题“订单”为 20 像素半粗体，不显示返回图标。
- 筛选区高度约 54，四项均分屏幕宽度；选中项为 16 像素深色文字及 16×3 红色指示线，未选中项为 14 像素灰色文字。
- 订单列表上方和卡片之间保留 8 像素灰色间隔。
- 卡片使用左右 16、上下 12 的内边距，内部间距遵循 Figma 的 12/8/4 像素节奏。
- 卖家头像为 24×24 圆形；昵称 14 像素半粗体。
- 状态颜色分别为：待支付 `#FF943D`、已支付 `#14A357`、已完成 `#808080`。
- 主操作按钮使用红色渐变；次操作按钮为白底灰色描边胶囊按钮。
- 价格与金额靠右排列，实付金额使用品牌红强调。

## 数据与筛选

订单展示模型包含 `id`、状态、卖家信息、服务名称、游戏、单价、数量、实付金额与操作项。三条示例数据分别对应待支付、已支付和已完成卡片。

筛选规则：

- `all`：显示全部示例订单。
- `inProgress`：显示待支付和已支付订单。
- `completed`：只显示已完成订单。
- `cancelled`：只显示已取消订单；当前无示例数据，因此展示“暂无已取消订单”空态。

筛选切换仅更新页面本地状态，不发起网络请求。数据与静态资源映射定义在组件外，避免渲染时重复创建。

## 交互边界

- 筛选项为可访问 `Pressable`，提供选中状态。
- 订单卡操作按钮提供明确的中文无障碍标签与按压反馈。
- 所有业务按钮只通过 `onAction(order, action)` 回调暴露交互边界，本次页面传入空实现，不虚构导航或业务结果。
- 列表使用 `FlatList`，底部留出 `AppTabBar` 和设备安全区所需空间。

## 性能与兼容性

订单卡组件使用 `memo`，列表使用稳定 ID 作为 key，筛选结果通过 `useMemo` 计算。布局仅使用 React Native 跨平台能力，不新增依赖，也不修改原生目录。

头像从 Figma 导出最终可见图层，按 40×40 以下实际显示需求保留 3x 像素密度后封装为 SVG，避免 Figma 隐藏变体造成包体膨胀。

## 错误与降级

本次使用本地数据，不涉及网络错误。筛选结果为空时显示与当前筛选对应的文案；长昵称和服务名称使用单行省略，防止窄屏破坏价格区域。

## 验证

- 运行 `npm run lint`。
- 运行 `npx tsc --noEmit`。
- 运行 Expo Web/Metro 导出，确认 `/order` 路由和 SVG 资源能被实际打包。
- 检查 375 像素设计宽度下的标题、筛选项、卡片间距、状态颜色和按钮排列。
- 检查更窄和更宽屏幕下文本不与金额重叠。
- 检查 iOS 与 Android 顶部安全区及现有底部 `AppTabBar` 不被重复渲染。

# 忘记密码与密码登录完善设计

## 目标

完善 React Native 登录流程，使其与 Web 统一登录实现保持一致：密码登录固定使用中国大陆手机号，支持密码显隐及忘记密码入口；新增完整的忘记密码页面，对接短信验证码和密码重置接口；重置成功后返回密码登录并回填手机号。

## 范围

本次包含：

- 密码登录手机号栏固定显示 `+86`，仅接受 11 位手机号。
- 密码框增加显示/隐藏密码按钮和“忘记密码”入口。
- 新增忘记密码页面，包括手机号、验证码、新密码、确认密码。
- 对接 `MOD` 验证码与忘记密码接口。
- 密码登录和密码重置提交前使用 MD5。
- 重置成功后返回密码登录模式并回填手机号。

本次不包含已登录用户修改密码、国际区号、账号名登录、服务端接口变更或新的第三方依赖。

## 架构

采用认证组件、SSO SDK、路由三层结构：

1. `packages/auth` 提供纯界面组件和表单校验，不直接依赖 Expo Router。
2. `packages/sso-sdk` 封装签名、MD5 和请求协议。
3. `src/app` 中的路由文件负责导航、参数传递和用户提示。

### 登录页

`LoginScreen` 增加以下能力：

- 通过初始属性接收登录模式和预填手机号。
- 密码模式仍展示 `+86`，手机号使用数字键盘且最多 11 位。
- 密码输入框使用 `secureTextEntry`，右侧按钮切换明文/密文。
- “忘记密码”通过 `onForgotPassword(phone)` 回调通知路由层。

`src/app/login.tsx` 读取 `mode` 和 `phone` 路由参数。忘记密码入口进入 `/forgot-password` 并携带当前手机号。重置成功返回时使用 `mode=password` 和手机号初始化登录页。

### 忘记密码页

`packages/auth/src/ForgotPasswordScreen.tsx` 为单页表单，包含：

- 手机号：固定 `+86`，只接受数字，最多 11 位。
- 验证码：只接受数字，最多 6 位。
- 新密码与确认密码：各自拥有独立显隐按钮，最多 16 位。
- 获取验证码：成功后启动 60 秒倒计时，倒计时期间不可重复发送。
- 保存按钮：提交期间禁用，防止重复请求。

页面不绘制假的系统状态栏或 Home Indicator。视觉沿用登录页的白色背景、浅灰输入框和红色主按钮。密码显隐图标保存为认证包本地资源，避免运行时依赖远程图片。

组件通过以下回调与外部通信：

- `onBack()`
- `onSendCode(phone)`
- `onSubmit({ phone, code, password })`

组件只在 `onSubmit` 成功返回后结束提交状态；成功提示及导航由路由层处理。

## 接口与数据流

### 密码登录

调用：

`POST /api/auth/oauth2/token`

请求数据：

```json
{
  "grant_type": "password",
  "username": "手机号",
  "password": "MD5后的密码",
  "scope": "openid"
}
```

`SsoClient.passwordLogin` 负责 MD5，不要求界面或路由层预加密。

### 发送重置验证码

复用：

`POST /api/auth/public/common/sms`

请求数据：

```json
{
  "phone": "手机号",
  "smsTemplate": "MOD"
}
```

### 重置密码

调用：

`POST /api/auth/public/common/forget-password`

请求数据：

```json
{
  "phone": "手机号",
  "smsCode": "验证码",
  "password": "MD5后的新密码"
}
```

`SsoClient.forgetPassword` 负责 MD5。`createAuthSsoAdapter` 暴露 `sendResetCode` 与 `forgetPassword`，让路由层不需要了解底层接口细节。

## 校验规则

- 手机号：`^1\d{10}$`。
- 验证码：1 至 6 位数字；接口是否要求固定 6 位由服务端最终校验。
- 密码长度：8 至 16 位。
- 密码不得包含空格。
- 密码必须在特殊字符、大写字母、小写字母、数字四类中至少包含三类。
- 特殊字符集合与 Web 实现一致：`%&@#!$^*()_+-=[]{};':"\\|,.<>/?`。
- 确认密码必须与新密码一致。

输入阶段限制长度和字符类型，提交阶段再次完整校验。校验失败不发起网络请求，并展示明确中文提示。

## 导航与成功状态

1. 用户在密码登录模式点击“忘记密码”。
2. 路由进入 `/forgot-password`，携带当前合法或未完成的手机号供回填。
3. 用户获取 `MOD` 验证码并提交新密码。
4. 接口成功后提示“密码重置成功”。
5. 使用 `router.replace` 返回 `/login?mode=password&phone=<手机号>`，避免返回键再次进入已完成的重置页。
6. 登录页显示密码模式并回填手机号，密码保持为空。

## 错误处理

- 本地校验错误在表单区域显示对应中文提示。
- 路由层捕获 SSO 请求错误并使用系统提示框展示；优先显示服务端 `info` 或 `message`，否则使用“发送验证码失败”或“密码重置失败”。
- 只有验证码接口成功后才启动倒计时。
- 请求失败时恢复按钮可用状态并保留已填写内容。
- 组件卸载时清理倒计时，避免卸载后更新状态。

## 测试与验证

使用 Node 内置测试覆盖：

- 密码登录请求中的密码已 MD5，其他字段保持正确。
- 忘记密码请求路径、手机号、验证码和 MD5 密码正确。
- `MOD` 验证码类型正确。
- 密码规则的有效与无效边界。

最终运行：

```bash
node --no-warnings --test packages/auth/*.test.mjs packages/sso-sdk/*.test.mjs
npx expo lint
npx tsc --noEmit
git diff --check
```

人工验收覆盖密码显隐、手机号回填、倒计时、重复点击保护、返回导航和成功后的登录模式。

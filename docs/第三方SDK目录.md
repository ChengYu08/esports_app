1. **「是否实际使用」**：业务代码是否真正调用；已引入但未调用的库单独标注。
2. **「涉及平台」**：`Android` / `iOS` / `双端`。部分 SDK 仅一端启用。

## 6. 与隐私政策条文的对应建议（设备信息相关）

以下条文可供法务改写，**非最终对外文本**：

1. **设备信息**：为保障即时通讯、开黑房、消息推送、本机号登录及支付安全，我们及合作方可能收集设备品牌、型号、操作系统版本、网络类型、IP 地址、运营商信息、应用版本、推送设备标识等；其中支付宝 SDK 可能收集 Android ID、OAID 等，具体以各 SDK 公示为准。
2. **存储 / 相册**：用于头像与图片上传、证据材料选择、本地缓存及 Android 应用升级安装等，在取得授权后访问相册或本地文件。
3. **传感器**：开黑房场景下，声网 SDK 可能在本地使用加速度等传感器以适配设备状态。
4. **剪贴板**：当前版本在用户主动复制时向剪贴板**写入**订单号等信息；**不读取**剪贴板内容。
5. **麦克风**：开黑房语音交流需要麦克风权限，采集语音内容用于实时通话。
6. **推送与自启动**：为确保及时接收消息，可能使用推送、前台服务及系统允许范围内的唤醒能力（以实际实现与商店合规要求为准）。
